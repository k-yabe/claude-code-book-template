# S078 品質修正スペック — 画像・アバター・音声ダイジェスト・UI改善

## 問題

| # | 問題 | 原因 |
|---|------|------|
| 1 | 画像が1枚も表示されない | シードデータのimage全削除、代替なし |
| 2 | Xアバターが表示されない | pbs.twimg.comのURLが404。フォールバックも不安定 |
| 3 | 音声が記事のベタ読み | APIキー未設定時のフォールバックが単純な記事結合 |
| 4 | 内容がわかりにくい | ダイジェストの構成・文体がNewsPicks品質に達していない |
| 5 | Xクリックでツイート元に遷移しない | シードデータのURLが空。div要素にhrefなし |

---

## 修正方針

### A. 画像（外部依存ゼロ戦略）

**原則: シードデータは外部リソースに一切依存しない。**

- シードデータの`image`は`null`のまま（偽画像を貼らない）
- 代わりに**CSS生成プレースホルダー**を全セクションで統一表示:
  - カテゴリ色のグラデーション背景
  - ソース名を中央に白文字表示
  - 視覚的に「画像枠」として成立するデザイン
- スクレイパー経由の実データでは`<img>`を表示（onerrorでCSSプレースホルダーにフォールバック）
- **結果**: シードでも実データでも画像枠が常に表示される

### B. Xアバター（外部依存ゼロ）

**原則: シードデータのアバターは外部URLを使わない。**

- シードデータ: `avatar`フィールドを空文字に統一。**CSSイニシャルアバター**を常時使用
  - 名前の頭文字をネイビー丸に金文字で表示
  - 外部画像依存ゼロ → 絶対に壊れない
- スクレイパー経由の実データ: `avatar` URLがあれば`<img>`表示（onerror→イニシャルフォールバック）

### C. 音声ダイジェスト（NewsPicks以上を目指す）

#### C-1. フォールバックスクリプト改善（APIキーなしでも高品質）

改善後（ラジオ番組構成）:
```
おはようございます。[日付]のマーケティング・ニュースダイジェストです。
今日のポイントは3つ。
1つ目、[サマリー1を短縮]。
2つ目、[サマリー2を短縮]。
3つ目、[サマリー3を短縮]。

では、詳しく見ていきましょう。

まず最も重要なニュースです。
[タイトル]。
[要約]。
これがなぜ重要かというと、[whyItMatters]。
具体的には、[actionItem]。

続いて、[タイトル]。
...

最後にまとめです。
今日押さえるべきは、[キーワード1]、[キーワード2]、[キーワード3]の3つです。
今日も頑張りましょう。
```

#### C-2. Claude生成ダイジェスト（プロンプト改善）

プロンプトを強化:
- 「冒頭で3つのポイントを予告」→「詳細」→「まとめで振り返り」の3幕構成を明記
- 記事間のつながり（「この流れを受けて」「一方で」）を必ず入れる指示
- 「あなたのチームがやるべきことは」で締める指示
- 文字数を1000〜1500字に拡大（5分に近づける）
