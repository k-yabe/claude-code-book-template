このセッションで行った作業をチームに共有するための文章を生成する。

## 出力ルール

- **タイトル**: `【対象 改善/修正/追加】一言で何をしたか` の形式
- **本文**: 以下の順で構成する
  1. 何を修正・改善したか（1文）
  2. 原因または背景（1〜2文）
  3. どう解決したか（1〜2文）
  4. 利用者への影響・確認方法（1文）
- **文体**: 日本語・言い切り形（〜した、〜する、〜なる）・ですます禁止
- **対象読者**: そのアプリや機能をふだん使っているチームメンバー（エンジニアでなくてもわかる表現）
- コードブロックや箇条書きは使わず、すべて文章で書く

## 手順

1. このセッションの会話履歴を振り返り、実施した変更内容を把握する
2. 上記ルールに従ってタイトルと本文を生成し、そのままチャットに出力する
3. 修正が複数ある場合は、最も重要な1件に絞るか、まとめて1本の文章にする
4. 出力後、「文体・長さ・内容を調整する場合は言ってください」と添える
