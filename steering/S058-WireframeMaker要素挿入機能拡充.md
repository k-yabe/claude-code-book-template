# [S058] Wireframe Maker 要素挿入機能拡充

## 目的

Wireframe Makerに個別要素の挿入機能を追加し、Figmaでワイヤーフレームを作成する際に必要な基本機能を補完する。現在はセクション単位のテンプレート方式のみで、見出しレベルの指定・図形・フォーム要素が挿入できない。

---

## スコープ

### やること
- [ ] 見出し要素の拡充（h1/h3/h4/h5/h6を個別挿入可能に。現在h2のみ）
- [ ] 基本図形の挿入（矩形・円・線・矢印のSVG要素を自由配置）
- [ ] フォーム要素の挿入（input/select/checkbox/radio/textareaのWFコンポーネント）
- [ ] 画像プレースホルダーの個別挿入
- [ ] ボタン要素の個別挿入（セクション外での単独配置）
- [ ] 挿入した要素のドラッグ移動・リサイズ
- [ ] 要素ピッカーUIの実装（ツールバーまたはサイドパネル）

### やらないこと（スコープ外）
- 完全な自由配置デザインツール化（Figma代替は目指さない）
- コンポーネント/シンボルシステム
- レイヤーパネル（別チケット）
- グループ化・整列ツール（別チケット）
- レスポンシブ制約設定

---

## 完了条件

- [ ] h1/h2/h3/h4/h5/h6を個別に挿入でき、SVGプレビューに反映される
- [ ] 矩形・円・線をキャンバス上に挿入でき、ドラッグ移動できる
- [ ] input/select/checkboxのWFモック要素を挿入できる
- [ ] 画像プレースホルダーを挿入できる
- [ ] 挿入した要素をクリックして選択・削除できる
- [ ] 既存のセクションベース機能が壊れない
