# [S072] BannerResizer サムネのセーフエリア自動余白

**ステータス**: 進行中
**作成日**: 2026-04-15
**完了日**: —

---

## 目的

BannerResizer の「一覧サムネイル（index）」(1920×1080) は、CMS 側で **上下24px / 左右100px** が自動カットされるため、要素を端まで配置すると確実に途切れる。
ユーザーが入れた要素を **絶対にカットさせない** ためのワンクリック対策として、
元画像をセーフエリア（1720×1032）内に縮小配置し、外側の余白を **元画像のぼかし拡大背景** で自動生成するモードを追加する。

---

## スコープ

### やること
- [x] index サムネカードに「セーフエリア内に収めて周囲を自動生成」チェックボックスを追加（デフォルト OFF）
- [x] ON 時：元画像を 1720×1032 内に contain 配置 + 1920×1080 全面に同画像を拡大ぼかししたものを敷く `createWithSafeAreaFit()` を実装
- [x] ON 時はカット領域オーバーレイを自動的に非表示にする（重複警告防止）
- [x] ダウンロード時もこのモードが反映されること
- [x] WHAT'S NEW / オンボーディングの updates 配列を更新
- [x] `docs/design.md` に設計を追記

### やらないこと（スコープ外）
- 背景生成方式の選択 UI（ミラー反射 / 平均色塗り など）。要望が出たら別ステアリングで追加
- index 以外のサイズ（MV/OGP）への適用
- AI inpainting / outpainting
