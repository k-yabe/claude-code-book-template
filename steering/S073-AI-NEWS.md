## 目的

AKKODiSマーケティングメンバーが「前日（〜過去数日）にマーケ業界で起きたこと」を朝イチで5分で把握できる、デザイン性の高い**ニュースダッシュボード**を Marketing Apps に追加する。複数媒体（Marketing系メディア／市場・テック動向／X上の有益情報）を横串で見られる構成にする。

> 元の仮称「Marketing Radar」は本タスクで **AI NEWS** に正式リネーム（シンプルさ優先・ユーザー指定）。

---

## スコープ

### やること

**A. 新規アプリ作成 `apps/ai-news/index.html`（1ファイル完結）**
- [ ] ヘッダー（ヒーロー）: 「Yesterday's Brief」表示（前日の日付・更新時刻・件数）
- [ ] カテゴリフィルタタブ: `すべて / マーケティング / 市場・業界 / AI / X（旧Twitter）から`
- [ ] ソースフィルタ（chip 型）: 媒体名で絞り込み（複数選択可）
- [ ] ニュースカードグリッド（main）: タイトル / 1〜2行サマリー / 媒体バッジ / カテゴリ / 公開日時 / 元記事リンク（外部）
- [ ] 「今日のXハイライト」サイドセクション: マーケに有益な投稿風カード3〜5件（出典明示 + 元投稿リンク）
- [ ] 検索ボックス（クライアントサイド全文検索）
- [ ] お気に入り（★）— LocalStorage に保存し、上部に「★お気に入りのみ」トグルを表示
- [ ] 既読管理: クリックすると既読扱いになりカードが薄く表示（LocalStorage）
- [ ] 「すべて既読にする / 既読をクリア」ボタン
- [ ] ローディング骨格 UI（スケルトン）と空ステート
- [ ] レスポンシブ（モバイルで1カラム、タブで2カラム、PCで3カラム）
- [ ] オンボーディングポップアップ（共通の `assets/onboarding.js`）

**B. データ供給方式（MVP方針）**
- [ ] バンドル同梱の **シードデータ** `NEWS_DATA = [...]`（マーケ媒体・市場媒体・X 投稿のサンプルを各カテゴリ均等に）
- [ ] エントリは `{ id, title, summary, source, sourceType: 'media' | 'x', category: 'marketing' | 'market' | 'ai', url, publishedAt, tags[] }` 形式に統一
- [ ] 「最終更新」表示はシードデータの最大 `publishedAt` を採用
- [ ] 将来 API/スクレイパー連携できるように、レンダリングは `renderNews(items)` で1関数化（将来の差し替えが楽な構造）

**C. ポータル統合**
- [ ] `index.html` の Marketing Apps グリッドにカード追加（`📰 AI NEWS`、NEWバッジ、card-tag-web）
- [ ] アプリ数カウントを 14 → 15 に更新
- [ ] `WHATS_NEW` 配列の先頭に NEW エントリを追加（必須5キー）

**D. ドキュメント**
- [ ] `docs/design.md` の機能一覧表に `AI NEWS` 行を追加
- [ ] CLAUDE.md ルール遵守: 1ファイルずつ実装 / WHAT'S NEW 更新必須 / オンボーディング `updates` も記載

### やらないこと（スコープ外）

- 実RSS/X API への接続（フロントオンリーでは CORS / 認証で破綻するため別タスク）
- サーバーサイドのスクレイパー実装（将来 `api/news-fetch.js` で対応予定）
- 記事本文の全文取得・要約生成
- ユーザーログイン / コメント / 共有
