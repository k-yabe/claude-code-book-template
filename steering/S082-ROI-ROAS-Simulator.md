## 目的

マーケティング施策（広告・キャンペーン）の費用対効果を、施策を打つ前にシミュレーションできるツールを提供する。広告費・CVR・客単価・粗利率などのパラメータから ROAS / ROI / CPA / 損益分岐点を即時計算し、「この予算でいくら売れれば黒字か」を直感的に把握できるようにする。

---

## スコープ

### やること
- [x] `apps/roi-roas-simulator/index.html` を新規作成（ピュアな client-side 計算機。API 不要）
- [x] ファネル型入力（広告費 → クリック → CV → 売上 → 粗利）でリアルタイム計算
- [x] 主要指標の算出: ROAS / ROI / CPA / CPC / CV数 / 売上 / 粗利 / 損益分岐ROAS / 黒字赤字判定
