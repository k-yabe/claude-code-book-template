# [S080] AI情報収集の自動化セットアップ（macOS / Claude Code）

**ステータス**: レビュー中
**作成日**: 2026-04-26
**完了日**: —（ユーザー Mac で `bootstrap.sh` が成功完了。明朝 07:00 の自動実行を観測したら「完了」へ）

---

## 目的

ユーザーのローカル macOS 環境（MacBook Air M3）に、AI情報を毎朝自動で収集する仕組みを構築する。3本柱：

1. `/last30days` スキル（SNS横断リサーチ）の導入
2. 指定サイトの定期巡回スキル（`daily-watch`）を `launchd` で毎朝7時に自動実行
3. 取得結果を `~/Documents/AI_Daily/`（または Obsidian Vault）に蓄積し、過去文脈として参照できる状態にする

---

## 重要な前提

- **本作業は本リポジトリ単体では完結しない**：`/plugin install`・`launchctl`・`~/Library/LaunchAgents/` などローカル macOS の操作が必須
- **本リポジトリの責務は「ユーザーが Mac で実行する成果物（テンプレート・ランブック）」を整備すること**
- 完全無料の範囲で実装する。有料 API は使わない（X / YouTube / TikTok / Instagram の `/last30days` 連携は ScrapeCreators API が有料のため除外）
- `/last30days` のゼロコンフィグ範囲（Reddit / Hacker News / Polymarket / GitHub / WebSearch）のみ使用
- 代替として Claude Code 標準の `WebSearch` + `WebFetch` で必要な範囲を補完
