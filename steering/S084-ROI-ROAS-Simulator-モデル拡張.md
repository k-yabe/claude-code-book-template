## 目的

ROI / ROAS Simulator の試算モデルを「広告費のみ・単発購入」から実態に近づける。具体的には ①人件費などの**その他固定費**、②**LTV（平均購入回数）**、③営業資料に複数の料金プランが載っているケースの**複数プラン比較**に対応する。UI はプログレッシブ・ディスクロージャー（普段はシンプル、必要なときだけ出る）で崩さない。

---

## スコープ

### やること
- [x] 入力に「その他固定費（人件費・制作費・ツール費など／月額）」を追加 → 総コスト＝広告費＋その他固定費で ROI / 損益分岐を再定義
- [x] 入力に「平均購入回数（LTV）」を追加 → 売上＝CV×客単価×購入回数（リピート反映）
- [x] `compute()` を純関数 `computeFrom(params)` ＋ `readInputs()` にリファクタ（プラン単位の試算を可能に）
- [x] プラン比較パネル（複数プラン時のみ表示）：指標×プランの表、列クリックで反映、最大利益を強調、削除/クリア、手動「この条件を比較に追加」
- [x] AI 抽出 JSON に `otherCost` `purchaseCount` `scenarios[]` を追加。資料に複数プランがあれば自動で比較に展開
- [x] コピー出力・所見パネル・損益分岐バー・必要CVR逆算を新モデルに合わせて更新
- [x] WHAT'S NEW・オンボーディング・docs/design.md 更新

### やらないこと（スコープ外）
- 試算期間（年間換算）の明示 UI（AI 抽出時は assumptions で月額換算を明記）
- ゴールシーク専用パネル（必要 CVR の逆算で代替）
- 入力値の localStorage 永続化（将来検討）

## 完了条件

- [x] その他固定費を入れると ROI・損益分岐・黒字赤字判定がそれを差し引いて計算される
- [x] 平均購入回数>1 で売上がリピート分反映され、表示も「LTV込み」になる

- [x] 既存（固定費0・購入回数1）の試算結果は従来と一致（後方互換）
