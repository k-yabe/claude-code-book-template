## 目的

Slide MakerのPPTX出力が「内容が適当・文字サイズがおかしい・図版ができていない」状態を修正し、プレビューと実際のPPTX出力の品質を一致させる。

---

## スコープ

### やること
- [ ] 図版データパースの堅牢化（単位付き文字列「100人」「1.2万円」→数値変換）
- [ ] 文字サイズのレイアウト別最適化（ハードコードPt値→コンテンツ適応型）
- [ ] chart/flow/tableの生成ロジック修正（データ検証・列幅自動調整・ステップ数対応）
- [ ] テンプレートマッピング修正（chart/flowが同名テンプレートで図版生成されない問題）
- [ ] notes（スピーカーノート）のPPTX反映
- [ ] SYSTEM_PROMPTでのデータ形式指示強化（数値は純粋な数値のみ、単位はunit/labelに分離）

### やらないこと（スコープ外）
- Unsplash API Production申請（運用対応）
- AI画像生成連携（DALL-E/Stability AI）
- テンプレート種類の追加
- プレビューUIの変更

---

## 完了条件

- [ ] chart.dataに「100人」等の単位付き文字列が来ても正しくパースされる
- [ ] 各レイアウトで文字サイズがコンテンツ量に応じて適切に設定される
- [ ] content-with-chartでグラフが正しく描画される
- [ ] content-with-flowでフロー図が正しく描画される
- [ ] テーブルの列幅がコンテンツに応じて調整される
- [ ] スピーカーノートがPPTXに含まれる
- [ ] 既存のPlaywrightテストがパスする
