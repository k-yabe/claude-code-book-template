## 目的

実運用フィードバックへの対応。(1) 営業資料に複数の料金パターン（展示会のブースサイズ別・協賛グレード別など）がある時に一部しか試算されない問題、(2) Mac など広い画面でレイアウトが崩れ・縦に長く見える問題、の2点を直す。

---

## スコープ

### やること
- [x] AI 抽出の料金プラン上限を `slice(0,4)`→`slice(0,8)` に拡大（取りこぼし防止）
- [x] プロンプト強化：複数料金は「漏れなく全部」、展示会はブースサイズ/小間数/協賛グレード違いを各プランとして列挙
- [x] `max_tokens` 1536→2400（プラン数増で JSON が途切れないように）
- [x] 推奨プランが資料の1プランと同一なら重複列を出さず該当列をアクティブ表示
- [x] レイアウト：`.container` を 1120px に拡張、入力欄を1カラム化（細い2列でラベルが折り返す崩れを解消）
- [x] ブレークポイント整理（`920px` 単一列＋sticky解除、イントロは `880px` 幅）
- [x] 回帰テスト追加（多数プラン全展開・推奨列付与）／WHAT'S NEW・オンボーディング・docs 更新

### やらないこと（スコープ外）
- 比較表の縦持ち⇔横持ち切替などの大改修
- PDF の画像（PNG）書き出し（S088 同様、ブラウザ標準印刷で代替）
