# [S059] Banner Resizer OGP — PNG固定・100KB上限対応

**ステータス**: 完了 <!-- 未着手 | 進行中 | レビュー中 | 完了 -->

## 目的

Banner ResizerのOGP出力をAKKODiS基準（100KB以下）に準拠させる。PNG固定を維持し、JPEGフォールバックを廃止する。

---

## スコープ

### やること
- [x] OGPの `maxBytes` を 300KB → 100KB に変更
- [x] OGPのJPEGフォールバックを廃止（常にPNG出力）
- [x] PNG超過時は警告表示（⚠ 超過）で対応
- [x] WHAT'S NEW 更新

### やらないこと（スコープ外）
- MV内容によるOGP適合判定の自動化（将来課題）

---

## 完了条件

- [x] OGPダウンロード時の拡張子が `.png` である（JPEGフォールバックなし）
- [x] OGPファイルサイズが100KB以下に収まる
- [x] 既存のMV・サムネイル機能に影響がない

## 参照

- ユーザー要望: OGPが100KB以下のAKKODiS基準に準拠すること

---

## 作業ログ

- 2026-04-09: 現状分析 — OGPは `forcePng: true` + 300KB上限。PNGが300KBを超えるとJPEGフォールバック発動。1200×630では高確率でフォールバックが起きていた
- 2026-04-09: 方針修正 — OGPはPNG固定を維持、JPEGフォールバックを廃止、上限100KBに変更
- 2026-04-09: 実装完了 — maxBytes 100KB、JPEG fallback削除、超過時は警告表示
