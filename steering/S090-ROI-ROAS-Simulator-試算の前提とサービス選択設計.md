## 目的

「資料をAIインポートした後、どのサービス（コンサル／ソリューション／アカデミー）で試算しているのか全く分からない」「サービスを選んでも試算が変わったのか分からない」という実運用フィードバックに対応する。サービスごとに成約率・客単価・粗利率が大きく異なり結果が変わるため、現在の試算前提を常時可視化し、資料インポートとサービス選択の関係を直感的にする。

---

## スコープ

### やること
- [x] 結果カード先頭に📌「試算の前提」バー（`basis-bar` / `updateBasis()`）を追加し、現在の数値が何由来かを常時表示
- [x] 資料インポート後にサービスを選ぶと、資料由来の予算・流入は維持し、そのサービスの経済性（成約率・客単価・粗利率・購入回数・人件費）だけを⚠目安として反映（`applyServiceEconomics`）
- [x] インポートなしのサービス選択は従来どおりプリセット一式をロード
- [x] 選択中サービスのチップを `.preset-chip.active`（ネイビー＋✓）でハイライト
- [x] 反映時にトースト（`showToast`）＋該当欄フラッシュで「変わったこと」を明示
- [x] 人件費「時給」欄の桁欠け（5000→500表示）修正（幅拡張＋スピナー非表示）
- [x] 回帰テスト追加（8e・計112アサーション）／WHAT'S NEW・オンボーディング・docs 更新

### やらないこと（スコープ外）
- サービスごとの経済性ベンチマーク値そのものの精緻化（別途）
- 複数サービスの同時並列比較（プラン比較表で代替可能）
