# [S061] BannerResizer クロップズーム機能（ズームイン）

**ステータス**: 完了 <!-- 未着手 | 進行中 | レビュー中 | 完了 -->
**作成日**: 2026-04-09
**完了日**: 2026-04-09

---

## 目的

Banner Resizer のクロップ機能にズームイン操作を追加し、被写体の一部にフォーカスした切り抜きを可能にする。集合写真の特定人物や、広い風景の一部分だけを使いたいケースに対応する。

---

## スコープ

### やること
- [x] ズームイン機能の実装（スクロールホイール / ピンチ操作）
- [x] ズーム倍率の表示（UI上にインジケーター）
- [x] ズーム + ドラッグの組み合わせ操作
- [x] 各出力サイズ（MV・OGP・サムネイル）ごとに独立したズーム状態
- [x] リセットボタン（ダブルクリックでズーム・位置を初期値に戻す）
- [x] WHAT'S NEW 更新

### やらないこと（スコープ外）
- ズームアウト（余白・背景埋めが必要で複雑）
- 回転機能
- フィルター・エフェクト

---

## 完了条件

- [x] ホイール操作でズームイン/アウト（1x〜3x）が動作する
- [x] ズーム中にドラッグで位置調整ができる
- [x] ズーム倍率がUIに表示される
- [x] リセット操作で初期状態に戻る（ダブルクリック）
