## 目的

試算結果を上長への共有・提案書への添付にそのまま使えるよう、結果カードから PDF 保存／紙印刷できるエクスポート機能を追加する。外部ライブラリに依存せず、ブラウザ標準の印刷機能のみで軽快に実現する。

---

## スコープ

### やること
- [x] 結果カードに「📄 PDF / 印刷」ボタン（`pdf-btn`）を追加し `window.print()` を起動
- [x] `@media print` でナビ・ガイド・資料アップ欄・入力フォーム・操作ボタン・フッターを隠し、結果カード／プラン比較表／AI 所見のみ全幅表示
- [x] ブランド名＋出力日付の印刷ヘッダー（`.print-header` / `print-date`）を追加（通常非表示・印刷時のみ）
- [x] `print-color-adjust:exact` で判定色・バッジ色を保持
- [x] リグレッションテストに印刷ボタン／印刷ヘッダー／日付スタンプの検証を追加（88→94 アサーション）
- [x] WHAT'S NEW・オンボーディング・docs/design.md 更新

### やらないこと（スコープ外）
- html2canvas 等での画像（PNG）書き出し（CDN 依存・サンドボックスのネットワーク制限を踏まえブラウザ標準印刷で代替）
- 印刷レイアウトの細かなページ送り最適化（break-inside:avoid で主要ブロックの分断のみ回避）
