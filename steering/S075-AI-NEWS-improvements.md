# [S075] AI NEWS — 体験改善（最終更新表示・進捗・ショートカット・タイムアウト・色階層）

**ステータス**: 完了
**作成日**: 2026-04-16
**完了日**: 2026-04-16

---

## 目的

S073/S074 で立ち上げた AI NEWS を「**毎朝開いて10分で全部目を通せる**」体験に磨き込む。
特に S074 完了条件にあった「ヒーローに最終更新時刻を出す」が未達だったため、これを補完しつつ周辺UXを底上げする。

---

## スコープ

### A. ヒーローの情報量強化（仕様完了条件の補完）
- [ ] `news.json` の `updatedAt` を「最終更新 MM/DD HH:MM」としてヒーローに表示
- [ ] シードデータ表示時は「（シードデータ）」と明示し、ユーザーに状態を伝える
- [ ] 既読率プログレスバー（X / Y 件 既読）

### B. 「読み切る」ためのアクション
- [ ] 「✓ 全部既読にする」ボタン（押したら即座に全件 read 状態へ）
- [ ] 「↓ 次の未読」ボタン（次の未読カードへスクロール＋focus）

### C. キーボードショートカット
- [ ] `/` で検索フォーカス
- [ ] `j` / `k` で次/前のニュースアイテムへ移動（focus + scroll into view）
- [ ] `f` でフォーカス中アイテムを★トグル
- [ ] `Enter` でフォーカス中アイテムを開く
- [ ] `?` でショートカット一覧モーダル

### D. 通信ロバストネス
- [ ] `loadRemote()` に AbortController + 8秒タイムアウト
- [ ] タイムアウト/失敗時はシードデータでそのまま起動（既存挙動を維持）

### E. 視覚階層
- [ ] TOP STORY = gold accent / BRIEFING = cyan accent / MORE = neutral の**色の三段階**を統一
- [ ] 重要度が見た瞬間に伝わるよう、各セクションヘッダにも階層インジケータ

### やらないこと

- メディアサイドの追加 / X API 連携（別タスク）
- アーカイブ閲覧UI（別タスク）
- 通知（メール）系 — 既存ワークフローで対応済み

---
