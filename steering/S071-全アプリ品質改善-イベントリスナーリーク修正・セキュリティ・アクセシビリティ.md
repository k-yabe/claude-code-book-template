# [S071] 全アプリ品質改善（イベントリスナーリーク修正・セキュリティ・アクセシビリティ）

**ステータス**: 完了 <!-- 未着手 | 進行中 | レビュー中 | 完了 -->
**作成日**: 2026-04-13
**完了日**: 2026-04-13

---

## 目的

全アプリを横断的に品質監査し、イベントリスナーのメモリリーク・セキュリティリスク・アクセシビリティ不足を修正する。S069（Wireframe Maker品質改善）で確立したパターンを他アプリにも適用し、プロダクション品質を底上げする。

---

## スコープ

### やること
- [x] Banner Resizer: setupCropDragのリスナー蓄積修正（AbortControllerで再登録前にabort）
- [x] Writing Checker: contenteditable へのペースト時にプレーンテキスト化（XSS防止）
- [x] Image Converter: 変換処理のキャンセル機能追加（ループ内フラグチェック方式）
- [x] SNS Post Generator: モバイルレスポンシブ対応（タブflex-wrap・プレビュー幅100%化）
- [x] OGP Checker: フェッチ中のローディングスケルトン表示（CSSアニメーション）
- [x] ドロップゾーン未対応アプリに `role="button"` と `aria-label` を追加（対象: Banner Resizer, Writing Checker）
- [x] 各アプリのオンボーディング `updates` 配列を更新
- [x] WHAT'S NEW 更新

### やらないこと（スコープ外）
- i18n対応（日本語以外の言語サポート）
- アプリ間の共通コンポーネント抽出（将来の作業単位で扱う）
- テスト自動化の追加
- Wireframe Maker・Slide Maker・Prompt Makerのドロップゾーン修正（S069で対応済み）

---

## 完了条件

- [x] Banner Resizer で画像を5回連続アップロードし、Chrome DevTools Performance Monitor の JS event listeners 数が初回と同数であること
- [x] Writing Checker で `<img onerror="alert(1)">` および `<script>alert(1)</script>` をペーストしてもスクリプトが実行されず、プレーンテキストとして挿入されること
- [x] Image Converter で変換中に「キャンセル」ボタンが表示され、クリックで処理が中断されること
- [x] SNS Post Generator がモバイル幅（375px）で横スクロールが発生せず、タブが折り返し表示されること
- [x] OGP Checker でURL入力後〜結果表示までスケルトンUIが表示されること
- [x] Banner Resizer・Writing Checker のドロップゾーンが VoiceOver で「画像をドラッグ＆ドロップまたはクリックして選択、ボタン」と読み上げられること
