# [S068] Wireframe Maker モード分離とテキスト編集改善

**ステータス**: 完了 <!-- 未着手 | 進行中 | レビュー中 | 完了 -->

**完了日**: 2026-04-10

---

## 目的

Wireframe Makerの「0から作成」と「サイトインポート」のモードを明確に分離し、テキスト編集できない箇所を解消して、直感的に使えるUXに改善する。

---

## スコープ

### やること
- [x] ウェルカム画面で「0から作成」「サイトから作成」を明確に分離したUI
- [x] 全セクションタイプの全テキスト要素にeditKeyを付与（編集可能化）
- [x] 編集可能テキストの視覚的ヒント（ホバー時のハイライト・カーソル変更）
- [x] クローン→WF変換のセクション抽出ロジック改善（div等の非セマンティック要素対応）
- [x] モード切替の導線改善（現在地がわかるUI）

### やらないこと（スコープ外）
- AI生成プロンプトの大幅リライト
- 新しいセクションタイプの追加
- エクスポート機能の変更

---

## 完了条件

- [x] ウェルカム画面から「ゼロから作る」「既存サイトから作る」の2つの明確な入口がある
- [x] 全17セクションのテキストがクリックで編集可能
- [x] 編集可能テキストにホバー効果（下線）がある
- [x] クローンモードでdivベースのサイトもセクション抽出できる

## 作業ログ

- ウェルカム画面を「ゼロから作る」（テンプレート/AIチャット）と「既存サイトから作る」（URL読込）に分離
- 6つのレンダラー（navigation, footer, video, logo-bar, comparison, sticky-cta）にsecパラメータとeditKeyを追加
- form/pricingの詳細テキスト（フィールド名、機能名）にもeditKey追加
- クローンモードのセクション抽出クエリを大幅拡張（wrapper/container/hero/banner/role属性、body直下divフォールバック、高さ30px未満フィルタ、重複排除）
- 抽出情報にtextPreview/ctaText/hasImage/hasForm/height/classNameを追加
- formatCloneStructureForAIを拡張して追加情報をAIプロンプトに反映
- WF変換ボタンをゴールド背景で強調（ct-btn-primary）
- クローンモード成功メッセージをStep 1/Step 2のガイド形式に変更
- WF生成後に「テキストはクリックで編集できます」ヒントを表示
- 空プレビューの案内文を4つの作成方法に更新
