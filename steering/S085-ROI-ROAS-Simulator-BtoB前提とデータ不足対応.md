## 目的

「営業資料に書いていない数値（CVR・客単価・粗利率・LTV 等の自社側数値）がある」「展示会・カンファレンスはクリック数が分からない」「どこが必須か分からない」という実運用の課題を解消し、**BtoB（AKKODiS のアカデミー／ソリューション／コンサルティング）前提で誰でも迷わず使える**ようにする。

---

## スコープ

### やること
- [x] データ不足の透明化：資料に無い値は AI に推測させず（null）、フロントで「⚠ 仮の値（目安）」と明示マーキング。重要前提が欠ければ判定を REVIEW（暫定）に
- [x] 仮値は `BTOB_BENCHMARK`／`DEFAULTS` で決定論的に補完（恣意的なデフォルトをやめ BtoB の目安に）
- [x] プリセットを AKKODiS BtoB 3事業ライン（アカデミー／ソリューション／コンサル）に刷新し、一般的な目安値を投入
- [x] 各入力に「必須／任意」バッジを付与
- [x] 展示会・カンファレンス対応：流入を「獲得数を直接入力」に一般化（リード/名刺/申込数、CPC 不要）。予算ラベルも「広告費・出展費など」に
- [x] AI プロンプトを BtoB・オフライン施策・データ不足前提に更新
- [x] WHAT'S NEW・オンボーディング・docs/design.md 更新

### やらないこと（スコープ外）
- 事業ラインごとの自動判別（資料内容からのライン推定）
- 入力値の localStorage 永続化

---

## 完了条件

- [x] 資料に無い項目は「⚠ 仮の値（目安）」と表示され、手入力/プリセット/リセットで解除される
- [x] 必須/任意がひと目で分かる
- [x] クリックの無い施策（展示会等）でも獲得数の直接入力で試算できる
- [x] BtoB 3事業ラインのプリセットが現実的な差（黒字/損益分岐/黒字）を示す（Node 検算）
