# [S062] WHAT'S NEW ポップアップ改善 — 自動表示・日付グループ化・可読性向上

## 目的

WHAT'S NEW の更新履歴が100件超の平坦なリストで読みにくい。ログイン後に新着のみを自動ポップアップ表示し、日付グループ化と説明文の折りたたみで可読性を大幅に改善する。

---

## スコープ

### やること

**A. ポータル WHAT'S NEW（index.html）**
- [x] ログイン後に新着エントリーのみモーダル自動表示（前回閲覧日以降）
- [x] 日付ごとにグループ化（日付ヘッダー付き）
- [x] 説明文の短縮表示（1行に収めて、クリックで展開）
- [x] 「すべて既読にする」で閉じ、次回は新しいエントリーがあるときだけ表示
- [x] 既存のWHAT'S NEWドロップダウンも同じグループ化UIに更新

**B. 各アプリ オンボーディング（onboarding.js + 各app HTML）**
- [x] onboarding.jsに「最近のアップデート」セクションを追加対応
- [x] 各アプリのinitOnboarding呼び出しにupdates配列を追加
- [x] アップデートがある場合は機能説明の下にタイムライン形式で表示

### やらないこと（スコープ外）
- WHATS_NEW配列のデータ構造変更（既存データはそのまま使う）

---

## 完了条件

- [x] 新着があるときだけモーダルが自動表示される
- [x] 日付ヘッダーでグループ化されている
- [x] 長い説明文が1行に収まり、クリックで全文展開できる
- [x] 閉じた後、同じエントリーでは再表示されない
- [x] ブランドカラー準拠（Navy/Gold/Cyan/White/Black のみ）
