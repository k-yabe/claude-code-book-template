❓ タスクボードの使い方
🤖 このボードとは？
AIエージェント（AIスタッフ）と自分のタスクを一覧で管理するカンバンボードです。
Obsidianのinboxにメモを書くと、自動でここにタスクが追加されます。
📋 カラムの意味
📬 未着手 タスクが割り振られたが、まだ誰も着手していない状態
🔄 進行中 AIまたは自分が今作業している状態
🚨 要確認 AIが判断できず止まっている状態。ここに溜まったら要対応！
カードを開いて理由を確認し、指示や判断をコメントに追記してください
✅ 完了 タスクが完了した状態
🚀 基本の使い方（3ステップ）
1 Obsidian の inbox にメモを書く
左サイドバーの inbox/ フォルダを右クリック → 新規ノート → タイトルにやりたいことを一言で書く
2 5分待つ（MacBookが起動中の場合）
自動でタスクが生成されてここに表示されます。すぐ確認したい場合は 🔄 同期 ボタンを押してください
3 このボードで進捗を確認する
カードをクリックするとステータス変更・コメント追記ができます
🔤 担当の自動振り分けルール
メモにキーワードを入れると担当AIスタッフが自動で決まります：
記事・ブログ・動画・台本・コンテンツ ✍️ コンテンツチーム
マーケ・マーケティング・SNS・プロモ 📣 マーケチーム
戦略・事業・ビジネス・収益 💡 ビジネスチーム
契約・法的・リーガル・規約 ⚖️ 法務
コード・バグ・実装・API・UI・デザイン 🛠️ エンジニアチーム
⚙️ ボタンの説明
＋ 新規タスク 手動でタスクを作成する
🔄 同期 GitHubから最新タスクを今すぐ読み込む
📤 エクスポート タスクデータをJSONファイルで保存する
🔑 トークン設定 GitHubのPersonal Access Tokenを設定する（初回のみ必要）
⚠️ 注意事項
  • MacBookがスリープ・電源オフの場合、自動タスク化は動きません
  • このボードはどのデバイスからでも閲覧できます（GitHub PATが必要）
  • 60秒ごとに自動で最新データを読み込みます
