# AI社員組織図

動画「シリコンバレー17年のプロが本気でAIエージェント使い込んだ結果全部見せます」の設計を実装。

## 設計原則（Googleの叡智より）

1. **専門化** — 1人に全部やらせない。役割を細分化して各自の領域にのみ責任を持たせる
2. **レビュー文化** — 重要な判断は必ず複数の目を通す（AIも同じ）
3. **書き物文化** — 引き継ぎはファイルで行う。会話・口頭で決めない
4. **意思決定範囲の明文化** — AIが判断してよい範囲と人間が確認すべき範囲を明確に定義

## AI社員の3要素

```
マニュアル（指示書） × 頭脳（AIモデル） × 机（独立セッション）
= AI社員
```

## モデル使用方針（コスト最適化）

```
Haiku  → 単純実行タスク（最安。チェック・フォーマット・振り分け）
Sonnet → オーケストレーター・中程度判断（メインの働き手）
Opus   → 重要な戦略判断のみ（滅多に出てこない。コスト最優先で節約）
```

## 使い方

各エージェントを呼び出す時は、対応するマニュアルファイルをシステムプロンプトに含める。
文脈エンジン（`context/context/`）のファイルも合わせて参照させること。
