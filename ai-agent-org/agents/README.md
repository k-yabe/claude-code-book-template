# AI社員組織図（20名体制）

イメージプロフェッショナルが集まる会社として、各専門領域をカバーする20名のAIエージェントで構成。
すべてのアウトプットはCOOによるレビューを経て、人間（CEO）に届けられる。

## 設計原則（Googleの叡智より）

1. **専門化** — 1人に全部やらせない。役割を細分化して各自の領域にのみ責任を持たせる
2. **レビュー文化** — COOが全アウトプットを検収。問題があればエージェント間でやり取りして解決
3. **書き物文化** — 引き継ぎはファイルで行う。会話・口頭で決めない
4. **意思決定範囲の明文化** — AIが判断してよい範囲と人間が確認すべき範囲を明確に定義

## AI社員の3要素

```
マニュアル（指示書） × 頭脳（AIモデル） × 机（独立セッション）
= AI社員
```

## 🔄 COOレビューフロー

```
エージェント → アウトプット生成
      ↓
    COO レビュー
      ↓
  ✅ 承認       🔄 差し戻し
      ↓               ↓
  人間(CEO)へ  担当エージェントへ改善指示
                      ↓
               再度COOレビュー（ループ）
```

COOが差し戻した場合、担当エージェントは修正後にタスクコメントへ「修正完了」と記録し、
COOが再レビューを行う。人間の介入なしにエージェント間で解決することを原則とする。

## モデル使用方針（コスト最適化）

```
Haiku  → 単純実行タスク（最安。チェック・フォーマット・振り分け）
Sonnet → オーケストレーター・中程度判断（メインの働き手）
Opus   → 重要な戦略判断のみ（滅多に出てこない。コスト最優先で節約）
```

## 使い方

各エージェントを呼び出す時は、対応するマニュアルファイルをシステムプロンプトに含める。
文脈エンジン（`context/context/`）のファイルも合わせて参照させること。
