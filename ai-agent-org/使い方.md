# AI Agent組織 — 使い方ガイド

## このシステムとは？

Obsidian・GitHub・Vercelを組み合わせて、AIエージェントを「会社の組織」のように動かす仕組み。

**イメージ：**
- 自分 = 社長（やりたいことをメモに書くだけ）
- AIエージェント = 各部門のスタッフ（コンテンツ・マーケ・エンジニアなど）
- Obsidian inbox = 社内の依頼ボックス
- タスクボード = 全社のタスク進捗を見るダッシュボード

メモを書くだけで担当エージェントに自動で割り振られ、タスクボードで進捗を確認できる。

## 日常の使い方

### 1. タスクを依頼する（Obsidianでメモを書く）

#### 手順

1. Obsidianを開く
2. 左サイドバーで `inbox` フォルダを右クリック
3. 「新規ノート」を選択
4. ファイル名にやりたいことを一言で書く（例：`ウェビナー集客コンテンツ`）
5. 本文に詳細を書く

#### メモの書き方

```
# タイトル（何をしたいか一言で）

本文：背景・目的・ターゲット・納期など、伝えたいことを自由に書く。
箇条書きでも文章でもOK。
```

**実際の例：**
```
# 来月のウェビナー集客LP・メールを作りたい

来月15日開催のウェビナーに向けてコンテンツを用意したい。

- ターゲット：B2BのITマネージャー層（従業員500名以上）
- ゴール：申込み100名
- 訴求：AI活用による業務効率化

必要なもの：LP（1枚）、招待メール（2通）、SNS投稿文（3本）
```

#### 担当エージェントの自動判定ルール

メモの中にあるキーワードで、担当が自動で決まる：

| こんなキーワードが入っていると | 担当エージェント | チーム |
|----------------------------|----------------|--------|
| 記事・ブログ・動画・スクリプト・台本・コンテンツ | content-director | コンテンツ |
| マーケ・マーケティング・SNS・宣伝・プロモ | marketing-director | ビジネス |
| 戦略・ビジネス・事業・収益・方針 | business-strategist | ビジネス |
| 契約・法的・リーガル・規約 | legal-review | ビジネス |
| 案件・パートナー・コラボ・提携 | partnership-manager | ビジネス |
| コード・バグ・実装・エラー・テスト・API | tech-lead | エンジニア |
| UI・フロントエンド・デザイン・CSS | frontend-engineer | エンジニア |
| 品質・QA・検証・チェック | qa-engineer | エンジニア |
| （どれにも当てはまらない） | tech-lead | エンジニア |

**優先度の自動判定：**

| キーワード | 優先度 |
|-----------|--------|
| 緊急・至急 | P0（最優先） |
| 重要・高優先 | P1 |
| （指定なし） | P2（通常） |
| いつか・低優先 | P3 |

### 2. タスクが自動生成される（待つだけ）

メモを保存すると、**MacBook Proが起動中であれば5分以内に自動でタスク化**される。

タスク化されると：
- `tasks/tasks.json` に新しいタスクが追加される
- `context/context/ai-handoffs/` に処理レポートが生成される
- タスクボードを開くと新しいタスクが表示される

**今すぐタスク化したい場合：**

ターミナルを開いて以下を実行：

```bash
cd ~/Documents/ai-agent-workspace/ai-agent-org
node scripts/task-dispatcher.js
```

### 3. タスクボードで進捗を確認する

**URL：**
> https://claude-code-book-template-git-main-k-yabes-projects.vercel.app/ai-agent-org/apps/task-board/

#### 初回アクセス時（デバイスごとに1回だけ）

1. 「🔑 トークン設定」ボタンをクリック
2. GitHub Personal Access Token（`github_pat_...` で始まる文字列）を貼り付け
3. OKを押すと保存される（次回から不要）

#### 画面の見方

```
[ New Assigned ]  [ In Progress ]  [ Blocked ]  [ Done ]
（未着手）         （進行中）        （要確認）    （完了）
```

- **New Assigned**：タスクが割り振られたが、まだ誰も着手していない状態
- **In Progress**：AIまたは自分が作業中
- **Blocked**：人間の判断・追加情報が必要で止まっている状態。**ここに溜まっていたら確認が必要**
- **Done**：完了

カードをクリックすると詳細・コメントが見られる。

#### 右上のフィルター

- **担当者**：特定のエージェントのタスクだけ表示
- **チーム**：コンテンツ・マーケ・エンジニアなど部門別に絞り込み

## コンテキストエンジン（AIが参照する情報）

Obsidianの `context/context/` フォルダにあるファイルは、AIエージェントが判断の拠り所にする「共有知識」。

| ファイル | 内容 | 更新タイミング |
|---------|------|-------------|
| `professional-identity.md` | 自分のプロフィール・職歴・価値観・スタイル | 変化があったとき |
| `philosophy.md` | AIエージェント組織の運営哲学・意思決定ルール | 方針変更時 |
| `technical-setup.md` | モデル使用方針・技術的な設定 | 変更時 |
| `visual-design.md` | デザインガイドライン | 変更時 |
| `ai-handoffs/` | AI間の引き継ぎ書・自動生成レポート | 自動 |

これらのファイルをObsidianで更新し、Obsidian Gitで同期すれば全エージェントに反映される。

---

## Obsidian Gitの同期について

Obsidianのプラグイン「Obsidian Git」が10分ごとに自動でGitHubにpush/pullする設定になっている。

- **push**：自分がObsidianで書いたメモ・更新がGitHubに反映される
- **pull**：AIエージェントが書いたレポートや更新が手元に届く

手動で今すぐ同期したい場合は、Obsidianのコマンドパレット（`Cmd+P`）→「Obsidian Git: Commit and push」を実行。

## よくある質問

**Q：inboxのファイルはタスク化されたら消えますか？**
消えない。ルール上「削除禁止」になっている。処理済みでもそのまま残る。

**Q：タスクボードで追加したタスクはGitHubに反映されますか？**
ブラウザのlocalStorageに保存されるだけで、GitHubのtasks.jsonには自動反映されない。Claude Codeから作業した場合はtasks.jsonに書き込まれる。

**Q：別のPC・スマホからタスクボードを見たい**
VercelのURLをブラウザで開いて、「🔑 トークン設定」からGitHub PATを入力するだけ。

**Q：MacBook Proがスリープ中・電源オフのとき**
自動タスク化は動かない。タスクボードの閲覧（読むだけ）はどのデバイスからでも可能。

**Q：AIエージェントに追加の指示を出したい**
タスクボードのタスクカードをクリック → コメント欄に追記する。

**Q：タスクのステータスを変えたい**
タスクボードでカードを開いて「ステータス」を変更する（ドロップダウンで選択）。
