# 📝 inboxの使い方

このフォルダにメモを書くだけで、AIエージェントが自動でタスク化します。

---

## ✍️ 書き方テンプレート

新しいノートを作って、下のテンプレートをコピーして使ってください。

```
# やりたいこと（タイトルは一言で）

## 背景・目的
なぜやりたいのか、どんな状況かを書く

## 詳細
- ターゲットは誰か
- ゴールは何か
- 期限はいつか
- 必要なアウトプットは何か（文章・LP・コード・分析など）
```

---

## 🔤 担当が自動で決まるキーワード

| 入れるキーワード | 担当 |
|----------------|------|
| 記事・ブログ・動画・台本・コンテンツ | ✍️ content-director |
| マーケ・SNS・プロモ・宣伝 | 📣 marketing-director |
| 戦略・事業・収益・方針 | 💡 business-strategist |
| 契約・法的・リーガル | ⚖️ legal-review |
| コード・バグ・実装・API | 🛠️ tech-lead |
| UI・デザイン・CSS | 🎨 frontend-engineer |

## 🚨 優先度キーワード

| キーワード | 優先度 |
|----------|--------|
| 緊急・至急 | P0（最優先） |
| 重要・高優先 | P1 |
| （何も書かない） | P2（通常） |
| いつか・低優先 | P3 |

---

## 📌 注意事項

- このファイル（`_テンプレート.md`）は削除しないでください
- 処理済みのメモは削除しなくてOK（ルール上残しておく）
- MacBookが起動中なら5分以内に自動タスク化されます
