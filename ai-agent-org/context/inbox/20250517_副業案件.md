#

## 背景・目的
副業の案件を1件増やしたい。

## 詳細
- 副業クラウドやシューマツワーカー、indeedなどのサイトを経由して、BtoBマーケティングのコンテンツマーケティングの案件もしくはウェビナー、カンファレンスの案件に応募したい。
- 新着の案件から優先的に応募したいと考えている。
- 完了までは1週間以内を想定している。
- まずは良さそうな案件のピックアップを完了させて、その後応募をしたい
- 自分のプロフィールを参考に、応募すべき案件をまとめておいてほしい。URLでも良い。そのあと自分で応募すべきかの判断をして応募する。
- エクセルとかで案件名、URL、応募理由みたいなのまとめておいてくれると嬉しいな。
