# このシステムでできること

> **一言で言うと：「やりたいことをメモするだけで、AIが仕事を進めてくれる」**

---

## どんなシステム？

あなたが「〇〇をやって」とメモを書くだけで、AIスタッフが自動で動いて結果を返してくれます。

```
あなた
  ↓  Obsidianにメモを書く
  
inbox（依頼ボックス）
  ↓  自動でタスク化
  
AIスタッフ（各専門チーム）
  ↓  自動で処理・成果物を作成
  
タスクボード（どこからでも確認）
  ↓  結果を確認・次の指示を出す
  
あなた
```

**できること例：**
- 「来月のウェビナー告知のSNS文を3つ書いて」→ Marketing Director が書いてくれる
- 「このAPIのバグ原因を調べて」→ Tech Lead が調査してくれる
- 「競合他社の動向を分析して」→ Business Strategist が分析してくれる

## 2台Mac体制

このシステムは2台のMacで役割分担しています。

```
💻 MacBook Pro M5                    ⚡ MacBook Air M3
（あなたのメイン作業機）              （常時起動・自動化サーバー）

・Obsidianでメモを書く               ・毎時間：タスク自動生成
・タスクボードで結果を確認             ・毎時間：AIがタスクを自動処理
・スリープしてOK                     ・毎朝7時：デイリーレポート生成
                                    ・毎朝2時：品質チェック
         │                                    │
         └─────── GitHub（データ保管庫） ──────┘
                           │
                    タスクボード（Vercel）
```

> ⚠️ **MacBook Air M3 はなるべく常時起動にしてください。**  
> スリープ中は AI の自動実行が止まります。

## 自動実行スケジュール

| 時刻 | 動作 |
|------|------|
| 5分ごと | inboxのメモを読んでタスクを自動生成 |
| 毎時（00分） | 未処理タスクをAIが自動実行・成果物を保存 |
| 毎朝 07:00 | 前日の完了タスク・進行状況をレポート生成 |
| 毎朝 02:00 | データの整合性チェック・品質レポート生成 |

> メモを書いてから最大1時間待つとタスクが処理されます。  
> 今すぐやりたい場合はターミナルで手動実行できます（→ 使い方ガイド参照）。

## タスクのステータス（進捗状態）

タスクは4つの状態を遷移します。

```
メモを書く
    ↓
📬 new-assigned（未着手）
    ↓  AIが処理を開始
🔄 in-progress（進行中）
    ↓
┌─────────────────────────────────────┐
│  AIが判断できた         AIが迷った  │
│         ↓                   ↓      │
│  ✅ done（完了）    🚨 blocked（要確認）│
│  成果物が保存される    あなたの判断待ち  │
│                             ↓      │
│                    コメントを書いて  │
│                    🔁 再実行ボタン  │
│                             ↓      │
│                    📬 new-assigned  │
│                    （再処理キューへ）│
└─────────────────────────────────────┘
```

> 🚨 **blocked になったらすぐ対応を！**  
> タスクボードの「Blocked」カラムが増えてきたら要確認のサインです。

## 優先度

メモにキーワードを入れると優先度が自動で設定されます。

| 優先度 | 意味 | 設定するキーワード |
|--------|------|-----------------|
| 🔴 P0 | 緊急・今すぐ対応 | 「緊急」「至急」「クリティカル」 |
| 🟠 P1 | 重要・優先して対応 | 「重要」「高優先」 |
| 🟡 P2 | 通常（何も書かなければこれ） | — |
| 🟢 P3 | 低優先・余裕があればでOK | 「低優先」「いつか」 |

## Obsidian Git の自動同期

Obsidian Git プラグインにより、メモは自動でGitHubと同期されます。

```
あなた（MacBook Pro）でメモを保存
  ↓  1分後に自動でGitHubへアップロード

GitHub（クラウド保管庫）
  ↓  MacBook Air M3 が検知

MacBook Air M3 がタスクを生成・AIを実行
  ↓  結果をGitHubへアップロード

あなた（MacBook Pro）に10分後に自動反映
```

**今すぐ手動で同期したい場合：**  
`Cmd+P` → `Obsidian Git: Commit and sync` → Enter
