# AI Agent Organization — システム概要

> **AIエージェントを「会社の組織」のように動かし、あなたの代わりに仕事を自動でこなすシステムです。**
>
> メモを書くだけで、マーケティング・コンテンツ制作・技術調査・法務チェックなど14種類のAIスタッフが自動で動きます。

---

## ⚡ このシステムでできること（30秒で理解）

| やること | 従来 | このシステム |
|---------|------|------------|
| SNS投稿文を3本作る | 自分で1〜2時間かけて書く | メモを書くだけ → 自動で完成 |
| 競合・市場調査をする | Web検索しながら数時間 | AIが自動でリサーチ・まとめ |
| APIのバグ原因を調べる | Stack Overflow を調べ回る | Tech Leadが自動で調査・報告 |
| 毎朝タスクの状況を把握する | Slackやメールを確認して回る | 毎朝7時に自動レポートが届く |

**コスト目安：月3〜5ドル**（大半のタスクはHaikuモデルで処理）

## ⏱️ 自動実行スケジュール

```mermaid
gantt
    title 1日のAI自動実行スケジュール
    dateFormat HH:mm
    axisFormat %H:%M

    section 常時稼働
    inbox監視・タスク自動生成（5分ごと） :active, 00:00, 24:00

    section 毎時
    AIタスク自動実行（毎時0分） :crit, 00:00, 01:00
    AIタスク自動実行（毎時0分） :crit, 01:00, 02:00
    AIタスク自動実行（毎時0分） :crit, 02:00, 03:00

    section 定時
    夜間QAチェック（02:00） :milestone, 02:00, 02:01
    朝会レポート生成（07:00） :milestone, 07:00, 07:01
```

| 時刻・頻度 | スクリプト | 内容 |
|-----------|-----------|------|
| **5分ごと** | task-dispatcher.js | inboxのメモを検知 → タスク自動生成・担当AI決定 |
| **毎時0分** | task-executor.js | 未処理タスクをAIが自動実行・成果物を保存 |
| **毎朝 07:00** | morning-standup.js | 前日完了・進行中・要確認タスクをレポート生成 |
| **毎朝 02:00** | overnight-qa.js | データ整合性チェック・品質レポート生成 |

## 🔄 タスクのライフサイクル

```mermaid
stateDiagram-v2
    [*] --> new_assigned : Obsidianにメモを書く\n↓ dispatcherが5分以内に検知

    new_assigned --> in_progress : executorが処理開始\n（毎時自動実行）

    in_progress --> done : AI処理完了\n成果物をprojectsに保存

    in_progress --> blocked : AIが判断できない\n（情報不足・承認が必要など）

    blocked --> new_assigned : あなたがコメントを追記\n🔁 再実行ボタンを押す

    done --> [*]

    note right of blocked
        タスクボードの
        Blockedカラムを
        定期確認してください
    end note
```

## 🔄 Obsidian Git 自動同期の仕組み

```mermaid
sequenceDiagram
    participant You as ✏️ あなた（MacBook Pro）
    participant OB as 📓 Obsidian Git
    participant GH as ☁️ GitHub
    participant M3 as ⚡ MacBook Air M3

    You->>OB: メモを保存
    Note over OB: 1分後に自動コミット
    OB->>GH: git push（自動）
    Note over M3: 5分ごとに polling
    M3->>GH: git fetch
    GH-->>M3: 新着ファイルを検知
    M3->>M3: タスクを自動生成
    M3->>GH: git push（タスク追加）
    Note over OB: 10分ごとに自動Pull
    GH-->>OB: 最新データを取得
    OB-->>You: Obsidianに結果が反映
```

**手動で今すぐ同期したいとき：**  
`Cmd+P` → `Obsidian Git: Commit and sync` → Enter
