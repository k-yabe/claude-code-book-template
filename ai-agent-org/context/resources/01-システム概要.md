# AI Agent Organization — システム概要

> AIエージェントを「会社の組織」のように動かし、あなたの代わりに仕事を自動でこなすシステムです。

## 3つの主要フロー

### フロー① タスクの自動生成（毎時）

```
あなたがメモを inbox/ に入れる
         │
         ▼
  task-dispatcher.js
  （1時間ごとに自動実行）
         │
    内容を分析して
  ・優先度を判定（P0〜P3）
  ・担当エージェントを決定
  ・組織を分類
         │
         ▼
  tasks/tasks.json に追加
         │
         ▼
  GitHub に自動 push
```

**例：** `inbox/` に「動画の台本を書いて」というメモを入れると → `content-director` エージェントに P2 タスクとして自動登録される

---

### フロー② AIによるタスク自動実行（毎時）

```
tasks.json の new-assigned タスクを確認
         │
         ▼
  task-executor.js
  （1時間ごとに自動実行）
         │
    担当エージェントに合わせた
    Claude モデルで処理
    ・調査・リサーチ系 → Web検索も使用
    ・戦略判断 → Sonnet（高性能）
    ・その他 → Haiku（高速・低コスト）
         │
         ▼
  成果物を context/projects/ に保存
  tasks.json のステータスを done に更新
         │
         ▼
  GitHub に自動 push
```

---

### フロー③ 毎朝の自動レポート（7:00）

```
  morning-standup.js
  （毎朝7時に自動実行）
         │
    tasks.json を読んで集計
    ・昨夜完了したタスク
    ・進行中・ブロック中
    ・チーム別状況
         │
         ▼
  context/context/ai-handoffs/standup-YYYY-MM-DD.md
         │
         ▼
  GitHub に自動 push
```

## 自動実行スケジュール

```
 02:00  ━━━━━━━━━━━━━━━━━━━━━━━━  overnight-qa.js
        データ整合性チェック・QAレポート生成

 07:00  ━━━━━━━━━━━━━━━━━━━━━━━━  morning-standup.js
        朝会レポート生成

 毎時   ━━━━━━━━━━━━━━━━━━━━━━━━  task-dispatcher.js
        inbox 監視 → タスク自動生成

 毎時   ━━━━━━━━━━━━━━━━━━━━━━━━  task-executor.js
```

> **すべて MacBook Air M3 の launchd（macOS スケジューラー）で自動実行されます。**  
> Mac がスリープ中は動きません。タスクボードの閲覧は常時 OK です。

## 2台 Mac 体制

このシステムは 2 台の Mac で役割分担しています。

```
┌─────────────────────────┐         ┌─────────────────────────┐
│   💻 MacBook Pro M5     │         │   ⚡ MacBook Air M3      │
│   （メイン作業機）       │         │   （常時起動・自動化サーバー）│
│                         │         │                         │
│ ・Obsidian でメモを書く  │──push──▶│ ・毎時 AI タスク自動実行  │
│ ・タスクボードを確認      │◀──pull──│ ・毎朝7時にレポート生成   │
│                         │         │ ・毎朝2時に品質チェック   │
└─────────────────────────┘         └─────────────────────────┘
            │                                   │
            └──────────── GitHub ───────────────┘
                          （共有データ保管庫）
                                │
                     ┌──────────▼──────────┐
                     │  📱 タスクボード     │
                     │  （Vercel でホスト）  │
                     │  スマホ・PC・どこでも  │
                     └─────────────────────┘
```

| Mac | 役割 | 状態 |
|-----|------|------|
| MacBook Pro M5 | メモを書く・タスクボードを確認 | 通常使用（スリープOK） |
| MacBook Air M3 | AI 自動実行サーバー | 常時起動推奨 |

## Obsidian Git 自動同期

Obsidian Git プラグインにより、メモは自動的に GitHub と同期されます。

```
MacBook Pro（Obsidian）
  │
  │  1分ごとに自動コミット → GitHub へ Push
  ▼
GitHub（クラウド保管庫）
  │
  │  10分ごとに自動 Pull → Obsidian に反映
  ▼
MacBook Air（自動実行サーバー）が inbox を検知 → タスク生成
```

**今すぐ手動で同期したい場合：**  
`Cmd+P` → `Obsidian Git: Commit and sync` と入力 → Enter

## タスクのステータス遷移

```
inbox に                  AIが
メモを入れる              自動実行
    │                       │
    ▼                       ▼
new-assigned  →  in-progress  →  done
（未着手）       （実行中）       （完了）
    │                │
    │           判断が必要な
    │           ケースのみ
    │                ▼
    └──────────  blocked
                 （要確認）
                      │
                 あなたがコメントを入れて
                 「🔁 再実行」ボタンを押す
                      │
                      ▼
                 new-assigned に戻る
```

## 優先度の意味

| 優先度 | 意味 | キーワード |
|--------|------|-----------|
| P0 🔴 | 緊急・今すぐ対応 | 「緊急」「至急」「クリティカル」 |
| P1 🟠 | 重要・今日中に | 「重要」「高優先」 |
| P2 🟡 | 通常（デフォルト） | — |
| P3 🔵 | 低優先・いつか | 「低優先」「いつか」 |
