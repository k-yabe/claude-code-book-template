# AIスタッフ一覧

> メモに書いたキーワードによって、担当するAIスタッフが自動で決まります。

---

## キーワードで担当が自動決定

メモにこのキーワードを入れると、自動で担当スタッフに振り分けられます。

| メモに書くキーワード | 担当スタッフ |
|-------------------|------------|
| 記事・ブログ・動画・台本・コンテンツ | ✍️ content-director |
| マーケ・マーケティング・SNS・プロモ・宣伝 | 📣 marketing-director |
| 戦略・事業・ビジネス・収益・方針 | 💡 business-strategist |
| 契約・法的・リーガル・規約 | ⚖️ legal-review |
| コード・バグ・実装・エラー・API・テスト | 🔧 tech-lead |
| UI・フロントエンド・デザイン・レイアウト・CSS | 🎨 frontend-engineer |
| DB・データベース・サーバー・インフラ・バックエンド | ⚙️ backend-engineer |
| 品質・QA・検証・チェック | 🧪 qa-engineer |
| （どれも当てはまらない） | 🔧 tech-lead（デフォルト） |

## エンジニアリングチーム

### 🔧 tech-lead（テックリード）
- **何をする人？** 技術的な調査・設計・コードレビュー
- **使うAIモデル** Haiku（Web検索あり）
- **依頼例** 「このAPIの設計を考えて」「このエラーの原因を調べて」

### 🎨 frontend-engineer（フロントエンドエンジニア）
- **何をする人？** 画面のデザイン・HTML/CSS/JavaScriptの実装
- **使うAIモデル** Haiku
- **依頼例** 「ボタンのデザインを修正して」「レイアウトを整えて」

### ⚙️ backend-engineer（バックエンドエンジニア）
- **何をする人？** データベース・サーバー・APIの設計と実装
- **使うAIモデル** Haiku
- **依頼例** 「DBのスキーマを設計して」「サーバーの処理を最適化して」

### 🧪 qa-engineer（QAエンジニア）
- **何をする人？** 品質チェック・テストケース作成・検証
- **使うAIモデル** Haiku
- **依頼例** 「この機能のテストケースを作って」「品質チェックして」

---

## コンテンツチーム

### ✍️ content-director（コンテンツディレクター）
- **何をする人？** 記事・動画台本・LP・メール・SNS投稿などの制作
- **使うAIモデル** Haiku（Web検索あり）
- **依頼例** 「YouTube台本を書いて」「ブログ記事を作って」

### 🎙️ brand-voice（ブランドボイス）
- **何をする人？** 文章のトーンがブランドに合っているかチェック
- **使うAIモデル** Haiku
- **依頼例** 「このテキストのトーンがブランドに合っているか確認して」

### 🔍 root-cause（ルートコーズ）
- **何をする人？** 表面的でない、本質的な原因の掘り下げ
- **使うAIモデル** Haiku
- **依頼例** 「この問題の本質的な原因を掘り下げて」

### 🚫 anti-ai-slop（アンチAIスロップ）
- **何をする人？** AIっぽいありきたりな表現を人間らしい文章に直す
- **使うAIモデル** Haiku
- **依頼例** 「このテキストのAIっぽい言い回しを直して」

---

## ビジネスチーム

### 📣 marketing-director（マーケティングディレクター）
- **何をする人？** マーケティング戦略・コピーライティング・SNS施策
- **使うAIモデル** Haiku（Web検索あり）
- **依頼例** 「このサービスのSNS施策を考えて」「集客コピーを書いて」

### 💡 business-strategist（ビジネスストラテジスト）
- **何をする人？** 事業戦略・収益モデル・重要な意思決定の分析
- **使うAIモデル** **Sonnet**（高性能モデル。戦略的判断に使用）
- **依頼例** 「この新規事業の可能性を分析して」「収益モデルを考えて」

### 🤝 partnership-manager（パートナーシップマネージャー）
- **何をする人？** 案件・提携・コラボの管理と整理
- **使うAIモデル** Haiku
- **依頼例** 「この提携の条件を整理して」「コラボ候補をリストアップして」

### ⚖️ legal-review（リーガルレビュー）
- **何をする人？** 契約書・利用規約の一次確認
- **使うAIモデル** Haiku（Web検索あり）
- **依頼例** 「この契約書の注意点を教えて」「規約の不明点を確認して」

> ⚠️ legal-review は一次確認のみです。重要な法的判断は必ず専門家（弁護士）に確認してください。

## インフラ運用チーム（システム内部専用）

### 📬 task-dispatcher（タスクディスパッチャー）
- **何をする人？** inboxのメモを読んでタスクを自動生成・担当を決める
- **これは手動で使うものではなく、システムが自動で動かす**

| スタッフ | 検索する内容の例 |
|---------|---------------|
| ✍️ content-director | 最新トレンド・事例調査 |
| 📣 marketing-director | 競合・市場調査 |
| 💡 business-strategist | 業界動向・事業分析 |
| 🔧 tech-lead | 最新技術・ライブラリ調査 |
| ⚖️ legal-review | 法改正・規制調査 |
