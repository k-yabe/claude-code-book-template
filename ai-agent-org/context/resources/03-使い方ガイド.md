## ① タスクを作る（一番よく使う）

### 方法A：inbox にメモを入れる（自動化向け）

```
context/inbox/ フォルダに .md ファイルを作る
         │
         ▼（最大1時間後に自動処理）
tasks.json にタスクが追加される
         │
         ▼（最大1時間後に自動実行）
AIが処理して context/projects/ に成果物保存
```

**ファイルの書き方：**
```markdown
# タイトルを1行目に書く

2行目以降に詳細を書く。
何をしてほしいか、背景、制約など。
```

**例：** `context/inbox/動画台本.md`
```markdown
# 5月のShift AI紹介動画の台本を書いて

対象: AIを始めたい20〜30代の社会人
時間: 3分程度
トーン: カジュアルで親しみやすく
強調したいこと: 初心者でもすぐ使える点
```

## ② タスクの状況を確認する

### タスクボードで確認（ビジュアル）

ブラウザで以下の URL を開く（スマホ・PC・どのデバイスからでも OK）。

```
https://claude-code-book-template-git-main-k-yabes-projects.vercel.app/ai-agent-org/apps/task-board/
```

GitHub から自動同期されるので、いつでも最新状態が見られます。

```
New Assigned    In Progress    Blocked    Done
（未着手）       （進行中）     （要確認）  （完了）
    │               │             │          │
    └── AIが次に    └── 現在処理  └── あなた  └── 終わった
        処理する        している     の対応      タスク
        タスク          タスク       が必要
```

**フィルタ機能：**
- 🔍 検索ボックス：タイトルや説明で絞り込み
- 担当者・チーム・組織でフィルタ
- 右上の「🔄 同期」で最新データを取得

#### 初回だけ：GitHub PAT（アクセストークン）を設定する

タスクボードが GitHub から最新データを読み書きするために、初回のみ設定が必要です。

```
1. タスクボードを開く
2. 右上の「🔑 トークン設定」をクリック
3. GitHub の Personal Access Token（github_pat_...）を貼り付け
4. OK を押す → 次回から不要（ブラウザに保存されます）
```

**PAT の取得方法：** GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens  
必要な権限：`Contents: Read and Write`（対象リポジトリのみ）

### 朝会レポートで確認（毎朝7時に自動生成）

`context/context/ai-handoffs/standup-YYYY-MM-DD.md` を見る。
前日の完了タスク、ブロック中、進行中が一覧でわかります。

## ③ ブロックされたタスクへの対応

AIが「人間の判断が必要」と判断したタスクは `blocked` になります。

```
┌─────────────────────────────────────────┐
│  T007  ⛔ AIの回答が必要です            │
│                                         │
│  ブロック理由: 予算の上限が不明のため    │
│  承認が必要です                          │
│                                         │
│  [コメントを追加...]                     │
│                                         │
│  [🗑 削除] [🔁 再実行] [閉じる]          │
└─────────────────────────────────────────┘
```

**対応手順：**
1. タスクをクリックしてコメントを確認
2. 必要な情報・判断をコメント欄に入力
3. 「🔁 再実行」ボタンを押す → `new-assigned` に戻り、次回AI実行で処理される

## ④ 成果物を確認する

## ⑤ よくある操作

### 緊急タスクを今すぐ処理させたい

```bash
# タスクを手動で今すぐ実行（1件のみ）
node scripts/task-executor.js --limit 1
```

### inbox のメモを今すぐタスク化したい

```bash
# 自動実行を待たずに今すぐ処理
node scripts/task-dispatcher.js
```

### 朝会レポートを今すぐ確認したい

```bash
# 画面に出力するだけ（ファイル保存しない場合）
node scripts/morning-standup.js --output /dev/stdout
```

### 特定タスクのAI実行をスキップしたい

タスクボードで該当タスクの `assigneeType` を `human` に変更（またはステータスを `done` にする）。

## ⑦ よくある質問（FAQ）

**Q: inbox のファイルはタスク化されたら消えますか？**  
→ 消えません。処理済みでもそのまま残ります（削除しなくて OK）。

**Q: MacBook Air がスリープすると AI は止まりますか？**  
→ はい。自動タスク実行は MacBook Air M3 が起動中のみ動きます。タスクボードの閲覧は常時 OK です。

**Q: スマホや別 PC からも使えますか？**  
→ タスクボードの URL を開いて GitHub PAT を入力すれば使えます。

**Q: AI に追加の指示を出したい**  
→ タスクボードでカードをクリック → コメント欄に追記 → 「🔁 再実行」ボタンを押す。

**Q: タスクのステータスを手動で変えたい**  
→ タスクボードでカードを開いて「ステータス」のドロップダウンで変更。

**Q: 今すぐ AI に実行させたい（スケジュールを待ちたくない）**

```bash
cd ~/Documents/ai-agent-workspace/ai-agent-org
node scripts/task-executor.js --limit 1
```

**Q: Obsidian のメモがすぐタスク化されない**  
→ Obsidian Git のプッシュが完了してから最大 1 時間待つか、手動実行：

```bash
node scripts/task-dispatcher.js
```

## トラブルシューティング

### タスクが生成されない

- `context/inbox/` にファイルがあるか確認
- ファイル名が `_` で始まっていないか確認（`_` で始まるファイルはスキップされます）
- ファイルの拡張子が `.md` か確認

### AIが毎回 blocked になる

タスクの説明が曖昧すぎる可能性があります。**誰が・何を・どのように** を具体的に書くと改善します。

```
❌ 悪い例：「マーケを考えて」
✅ 良い例：「Shift AI の法人向けプランを 30〜40代の管理職に売るための
           SNSマーケ施策を3つ提案して。予算は月10万円以内で。」
```

### launchd が動いていない確認

```bash
# 登録済みジョブの確認
launchctl list | grep kyabe

# ログの確認
tail -50 ~/Library/Logs/ai-agent-dispatcher.log
tail -50 ~/Library/Logs/ai-agent-executor.log
```
