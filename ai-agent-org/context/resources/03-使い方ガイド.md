## 初回セットアップ

### ① タスクボードにGitHubトークンを設定する

タスクボードがGitHubのデータを読み書きするために、初回だけ設定が必要です。

```
手順：
1. タスクボードを開く
   → https://claude-code-book-template-git-main-k-yabes-projects.vercel.app/ai-agent-org/apps/task-board/

2. 右上の「🔑 トークン設定」をクリック

3. GitHubのPersonal Access Token（github_pat_...）を貼り付け

4. OKを押す → 次回から不要（ブラウザに保存されます）
```

**GitHubトークンの取得方法：**
```
GitHub → 右上アイコン → Settings
→ Developer settings（左メニュー下部）
→ Personal access tokens → Fine-grained tokens
→ Generate new token

設定：
- Repository access: このリポジトリのみ
- 権限: Contents → Read and write
```

### ② 自分の情報をAIに教える（ブリーフィング）

AIスタッフがあなたのことを知っていれば、より的確な仕事をしてくれます。  
`context/context/` フォルダの以下のファイルを自分の情報で更新してください。

| ファイル | 書くこと |
|---------|---------|
| `professional-identity.md` | 職歴・スキル・肩書き・SNS |
| `philosophy.md` | 仕事の哲学・価値観・大切にすること |
| `visual-design.md` | ブランドカラー・フォント・デザインルール |
| `technical-setup.md` | 使っている技術スタック・ツール |

MacBook Air M3 のターミナルで以下を実行します。


これで MacBook Air M3 が自動サーバーとして動き始めます。

## 毎日の使い方

### STEP 1 ✏️ Obsidianにメモを書く

Obsidian で `inbox` フォルダに新規ノートを作成します。

```
📁 Obsidian vault
 └── 📥 inbox/
      └── ← ここに新しいノートを作る
```

**書き方テンプレート：**

```markdown
# やりたいことを一言で書く（タイトル）

## 背景・目的
なぜやりたいのか、どんな状況かを書く

## 詳細
- ターゲットは誰か
- ゴールは何か
- 期限はいつか
- 必要なアウトプットは何か（文章・LP・コード・分析など）
```

**実際の書き方例：**

```markdown
# 来月のウェビナー集客コンテンツを作りたい

## 背景
来月15日にウェビナー開催。集客コンテンツが必要。

## 詳細
- ターゲット：B2BのITマネージャー（従業員500名以上）
- ゴール：申込み100名
- 必要なもの：LP×1、招待メール×2、SNS投稿文×3
- 期限：来月10日まで
```

> 💡 **担当は自動で決まります。**  
> メモに「SNS」「マーケ」などのキーワードを入れると、自動でMarketing Directorに振り分けられます。  
> キーワード一覧は「エージェント一覧.md」を確認してください。

---

### STEP 2 ⏳ 待つ（最大1時間）

メモを保存すると、Obsidian Gitが自動でGitHubにアップロードします。  
その後 MacBook Air M3 が検知して、タスクを自動生成・AI処理します。

```
メモを保存
  ↓  〜1分  Obsidian Gitが自動でGitHubへアップロード
  ↓  〜1時間  MacBook Air M3 がタスクを自動生成
  ↓  〜1時間  AIがタスクを処理・成果物を保存
  ↓
タスクボードに「done」として反映
```

> 🚀 **今すぐやりたい場合は手動実行できます（→ [今すぐやりたいとき](#今すぐやりたいとき)を参照）**

## タスクボードの使い方

### 新規タスクを手動で作る

```
① 「＋ 新規タスク」ボタンを押す（またはキーボード「N」）
② タイトル・担当者・優先度を設定
③ 「作成」ボタンを押す
```

### 絞り込み・検索

- 🔍 **検索ボックス**：タイトルや説明文で絞り込み
- **担当者フィルタ**：特定のエージェントのタスクだけ表示
- **チーム・組織フィルタ**：チーム単位で絞り込み
- 🔄 **同期ボタン**：最新データをGitHubから取得

### タスクの詳細を見る

タスクカードをクリックすると詳細が開きます。
- コメント欄：AIからの結果・経過報告が表示されます
- ステータス変更：ドロップダウンで手動変更できます
- 成果物リンク：`context/projects/` への直リンクが表示されます

### 朝会レポートで一括確認（毎朝7時に自動生成）

Obsidian の以下のパスに毎朝レポートが届きます。

```
context/context/ai-handoffs/standup-YYYY-MM-DD.md
```

内容：
- 昨日完了したタスク
- 現在進行中のタスク
- 要確認（blocked）のタスク一覧
- 未着手タスクの一覧

## AIが止まったとき

AIが「人間の判断が必要」と判断したとき、タスクは `blocked`（要確認）になります。

**対応手順：**

```
① タスクボードの「Blocked」カラムにあるカードをクリック

② 「ブロック理由」を読む
   例：「予算の上限が不明なため承認が必要です」

③ コメント欄に判断・情報を書き込む
   例：「予算は月10万円まででOKです」

④ 「🔁 再実行」ボタンを押す
   → next タスクが「new-assigned」に戻り、次回の自動実行で処理されます
```

## 成果物の確認方法

AIが処理したタスクの成果物は `context/projects/` フォルダに保存されます。

```
context/projects/
├── T002-2026-05-17-output.md   ← T002の成果物
├── T004-2026-05-17-output.md
└── ...
```

**Obsidianから見る場合：** vault内の `projects/` フォルダを開く

**タスクボードから見る場合：** タスクカードのコメント欄にあるリンクをクリック → GitHubで開く

## よくある質問

**Q: メモを書いてもタスクにならない。どれくらい待てばいい？**  
→ 最大1時間かかります。Obsidian Gitが同期済みかを確認してください（`Cmd+P` → `Obsidian Git: Commit and sync`）。すぐやりたい場合は手動実行してください。

**Q: inboxのファイルは処理されたら消えますか？**  
→ 消えません。処理済みでもそのまま残ります。削除しなくてOKです。

**Q: MacBook Airがスリープすると止まりますか？**  
→ はい。自動実行はMacBook Air M3が起動中のみ動きます。タスクボードの閲覧は常時OKです。

**Q: スマホや別のPCからも使えますか？**  
→ タスクボードのURLを開いてGitHub PATを入力すれば使えます。

**Q: AIに追加の指示を出したい**  
→ タスクボードでカードをクリック → コメント欄に追記 → 「🔁 再実行」ボタンを押す。

**Q: 特定のタスクをAIに処理させたくない**  
→ タスクボードでそのタスクを開き、ステータスを `done` に変更するか、assigneeTypeを `human` に変更する。

**Q: AIの回答が薄い・的外れ**  
→ メモの書き方が曖昧な可能性があります。「誰が・何を・どのように・いつまでに」を具体的に書くと改善します。

## トラブルシューティング

### タスクが生成されない

```
確認項目：
✅ context/inbox/ にファイルがあるか
✅ ファイル名が _ で始まっていないか（_から始まるファイルはスキップされます）
✅ ファイルの拡張子が .md か
✅ Obsidian Git で同期済みか（Cmd+P → Commit and sync）
✅ MacBook Air M3 が起動・ログインしているか
```

### AIが毎回 blocked になる

タスクの説明が曖昧すぎる可能性があります。  
**「誰が・何を・どのように」を具体的に書くと改善します。**

```
❌ 悪い例：「マーケを考えて」

✅ 良い例：「Shift AIの法人向けプランを30〜40代の管理職に売るための
           SNSマーケ施策を3つ提案して。予算は月10万円以内で。」
```

### 自動実行が動いているか確認したい

MacBook Air M3 のターミナルで：

```bash
# 登録済みジョブの確認
launchctl list | grep kyabe

# ログの確認
tail -50 ~/Library/Logs/ai-agent-dispatcher.log
tail -50 ~/Library/Logs/ai-agent-executor.log
tail -50 ~/Library/Logs/ai-agent-standup.log
```

### タスクボードでデータが表示されない

```
確認項目：
✅ GitHub PATが設定されているか（右上「🔑 トークン設定」）
✅ PATの権限が「Contents: Read and write」になっているか
✅ 右上の「🔄 同期」ボタンを押したか
```
