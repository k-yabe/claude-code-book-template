## 📖 改訂版：inboxの使い方ガイド

### 目的
個人的なアイデア・やるべきことを素早くメモし、AIエージェントが自動解析して適切なチームに割り当てる仕組み。

### 利用フロー

```
1. inbox/ フォルダにメモを書く
2. macOS Notchesが起動中の場合、自動的に5分以内に解析
3. テンプレートのキーワードと優先度を検出
4. 対応するエージェントのチームに自動タスク化
5. エージェントが実行開始
```

---

### ✍️ メモ作成時のルール

#### 1. ファイル名
```
inbox/YYYYMMDD_[一言でのタイトル].md
```
例）`inbox/20250115_AIエージェントのエラーハンドリング改善.md`

#### 2. 必須セクション
```markdown
# やりたいこと（タイトルは一言で）

## 背景・目的
なぜやりたいのか、どんな状況かを書く

## 詳細
- **ターゲット**：誰のため、誰が使うのか
- **ゴール**：何を達成したいのか
- **期限**：いつまでか
- **成果物**：何を提出するのか（文章・LP・コード・分析など）

## 参考資料（あれば）
- リンク、既存ドキュメント、背景情報など
```

#### 3. 担当自動割り当てキーワード

| キーワード | → 担当 | 優先度イメージ |
|----------|--------|------------|
| **記事・ブログ・動画・台本・コンテンツ** | ✍️ content-director | 週単位 |
| **マーケ・SNS・プロモ・宣伝** | 📣 marketing-director | 即座〜週単位 |
| **戦略・事業・収益・方針** | 💡 business-strategist | 月単位 |
| **契約・法的・リーガル** | ⚖️ legal-review | 即座 |
| **コード・バグ・実装・API** | 🛠️ tech-lead | 即座〜週単位 |
| **UI・デザイン・CSS** | 🎨 frontend-engineer | 週単位 |

**複数キーワード含む場合**：最初に出現したキーワードの担当に割り当て。同時進行が必要なら複数タスク化。

#### 4. 優先度キーワード

| キーワード | 優先度 | 対応期限 |
|----------|--------|---------|
| **緊急・至急・今すぐ** | P0 | 今日〜明日 |
| **重要・高優先** | P1 | 3日以内 |
| （指定なし） | P2 | 1週間以内 |
| **いつか・低優先・参考** | P3 | 月単位 |

---

### 🚨 よくあるミス

| ❌ やらないこと | ✅ 正しい書き方 |
|------------|----------|
| 背景なしで「〇〇を作って」 | 背景→目的→具体的なゴール・成果物を順序立てて |
| 曖昧な期限「いつか」 | 「2月末までに」「次回ABMメーティング前に」と具体日を |
| キーワードなし | 必ず1つ以上のキーワードを含める |
| 処理済みファイルの削除 | 削除しない（履歴として保持） |

---

### 📍 システムの動作保証

- **MacBook起動中**：5分以内に自動検出・タスク化
- **MacBook非起動**：起動時に遡って処理
- **既に処理済み**：二重処理されない（UUID / タイムスタンプで重複チェック）
