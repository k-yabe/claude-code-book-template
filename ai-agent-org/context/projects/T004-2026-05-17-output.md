## 3. ブランドボイスの4軸

### 軸1：実務家（Practitioner）
> 理論ではなく現場の話をする

- 「自分がやってみた結果」「実際のプロジェクトで起きたこと」を起点にする
- 抽象論・概念論だけで終わらない。必ず具体例・数字・手順を添える
- 「〜と言われています」より「自分はこうしている」を優先する

### 軸2：先行者（Pioneer）
> 半歩先を見せるが、置いてきぼりにしない

- 最新のAIツール・手法を誰よりも早くキャッチし、実務で試した上で語る
- ただし、読者を「すごいですね」で終わらせない。「あなたも明日できる」まで落とし込む
- 技術的すぎる話は翻訳してから届ける

### 軸3：フラット（Flat）
> 上から教えるのではなく、隣で話す

- 同じ現場で働くプロとして横並びで話す
- 「〜すべきです」「〜しなければなりません」の上から目線を避ける
- 「自分はこうしています」「一緒に考えましょう」のスタンスを保つ

### 軸4：スピード重視（Velocity）
> 考えながら走る姿を見せる

- 完成形だけを見せるのでなく、試行錯誤のプロセスも開示する
- 「まず動いてみる」「PDCAを速く回す」姿勢をコンテンツにも反映する
- 長い前置きを避け、結論・価値を早く届ける

## 4. トーン設定

### 基本トーン
**「熱量のある、読みやすいプロの言葉」**

| 場面 | トーン | 具体例 |
|------|--------|--------|
| SNS投稿 | カジュアル＆熱量あり | 「やっと検証できた。結果が想定以上だったので共有します。」 |
| メール・LP | プロフェッショナル＆具体的 | 「ABM施策でMQL獲得数を前四半期比140%に伸ばした方法をお伝えします。」 |
| 記事・ブログ | フラット＆実務的 | 「今回はウェビナー設計で使っているAIプロンプトをそのまま公開します。」 |
| ウェビナー台本 | 親しみやすく、テンポよく | 「むずかしい話はしません。今日は手を動かせるところまで行きます。」 |

### トーンの温度感
```
冷静・フォーマル ←────────────────────→ 熱量・カジュアル
                          ★ ここに位置する（やや熱量よりの中央）
```

## 5. 文体ルール

### 基本ルール
- **一文を短く**：1文は原則60文字以内。長くなる場合は分割する
- **体言止めを適度に使う**：リズムを生むが、多用しない（3文に1回まで）
- **読点は適切に**：「、」が連続3つ以上続く文は再構成する
- **漢字・ひらがなのバランス**：読みやすさ優先。難解な漢字はひらがなに開く

### 人称
- 自分：「私」（記事・LP）、「僕」（SNS・カジュアルな場面はOK）
- 読者：「あなた」「皆さん」（「御社」「読者の方々」は堅すぎ）

### 文末表現
- **推奨**：「〜しています」「〜でした」「〜してみてください」「〜だと思います」
- **避ける**：「〜でございます」「〜かと存じます」（過剰敬語）
- **避ける**：「〜でしょうか？」の多用（自信なさそうに見える）

## 7. 禁止表現・NG ワード

### 絶対NG（ブランドイメージを損なう）
| NGワード/表現 | 理由 | 代替案 |
|-------------|------|--------|
| 「革命的」「破壊的イノベーション」 | 大げさ・陳腐化している | 「大きく変わる」「根本から変える」 |
| 「〜すべき」「〜しなければなりません」 | 上から目線 | 「〜がおすすめです」「〜を試してみてください」 |
| 「弊社の〜」（個人コンテンツで） | 会社と混同させる | 「私が〜」「今回のプロジェクトで〜」 |
| 「AIが全てを解決します」 | 過剰な期待を生む | 「AIを使うことで〜の工数が減ります」 |
| 「誰でも簡単に」 | 信頼性を損なう | 「手順通りに進めれば〜できます」 |
| 「最強」「最高」「神ツール」 | 根拠なき誇張 | 「私が最も効果を感じているのは〜」 |
| 「〜という概念」 | 説明的すぎ・学術的 | シンプルに言い換える |

### 注意ワード（文脈次第でOK/NG）
| ワード | 注意点 |
|--------|--------|
| 「絶対」 | 保証的なニュアンスに注意。「多くの場合〜」に言い換えを検討 |
| 「簡単」 | 「〜のステップで」など手順を示す形で使う |
| 「無料」 | 商業的すぎる文脈では避ける |
| 「爆速」「神速」 | SNSではOK、記事・LP・メールでは避ける |

## 8. コンテンツ種別ごとの追加ルール

### SNS（X / LinkedIn）
- **X**：テンポよく、結論先出し。改行を活用し、スキャンしやすく
- **LinkedIn**：少しフォーマルに。実績・数字を含め、プロ読者に刺さる内容に
- ハッシュタグは3つ以内（乱用しない）
- 自己PRより「与える情報」を優先する

### メール（リードナーチャリング・ウェビナー告知）
- 件名：25文字以内を目安。具体的な数字・ベネフィットを入れる
- 本文：400〜600文字以内（スキミングできる長さ）
- CTA（行動喚起）：1メール1アクションに絞る

### LP（ランディングページ）
- ファーストビューで「誰に・何が得られるか」を明示
- 社会的証明（数字・実績・事例）を必ず含める
- 専門用語は使うが、初見で意味が取れる補足を添える

### 記事・ブログ
- 冒頭200文字で「読む理由」を与える
- 見出しはSEOと可読性の両立（検索意図を意識）
- 結論・まとめを末尾に置く（再確認できる構成）

### ウェビナー台本
- 口語調。書き言葉と読み言葉のギャップをなくす
- 1スライドにつき話す内容は1トピックまで
- 参加者への問いかけを適度に挟む（一方的にならない）

## 9. 参照ケーススタディ（ボイスの参考例）

### Good Example ✅
```
ABMを始めたばかりの頃、ターゲットアカウントの選定に2週間かけていました。
今はAIを使って4時間で終わります。
何が変わったか、手順ごとに説明します。
```
→ 具体的・自分の話・結論が早い・読者に価値を渡している

### Bad Example ❌
```
昨今のAI技術の革命的な進化により、BtoBマーケティングのパラダイムシフトが
加速しています。皆様もぜひAIを活用した施策を検討されるべきでしょう。
```
→ 抽象的・評論家的・上から目線・行動につながらない
