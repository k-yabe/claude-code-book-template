# AKKODiS XLSX Skill

このスキルは AKKODiS ブランド準拠の Excel ファイルを生成する。

## いつ使うか

- 「KPI ダッシュボードを Excel で」「案件管理表を作って」
- 「予算管理シートが欲しい」「月次の売上レポートを xlsx で」
- 「AKKODiS のブランドで Excel」「会社の表記ルールを守った Excel」

## 入力フォーマット

Markdown ライクで「シート構成」と「データ」を渡す。データは Markdown 表で記述する。

```
# タイトル: 2026 Q2 KPI ダッシュボード

## サマリー [chart]                ← [chart] でチャート自動追加
| 指標         | 目標   | 実績   | 達成率 |
| ------------ | ------ | ------ | ------ |
| リード獲得   | 5,000  | 6,120  | 122%   |
| MQL 創出     | 1,500  | 1,420  | 95%    |

## 案件一覧
| 案件名 | 業種 | 担当 | 金額(千円) |
| ------ | ---- | ---- | ----------- |
| A社 提案 | 製造 | 田中 | 12,000      |
```

特殊シンタックス:

| 記法 | 効果 |
|------|------|
| `## <名前>` | シート追加 |
| `## <名前> [chart]` | シートに棒グラフを追加（先頭文字列列をカテゴリ、最初の数値列を値に） |

## 生成手順

1. `brand/style-guide.md` と `brand/notation-rules.md` を**必ず先に読む**。
2. `scripts/build_xlsx.py` を実行：
   ```bash
   python scripts/build_xlsx.py --input <入力 .md> --output <出力 .xlsx>
   ```
3. スクリプトが以下を自動で行う：
   - **ヘッダー**: Navy 背景 + 白文字 Bold（Noto Sans JP, 11pt）
   - **ゼブラ**: 偶数行に淡いグレー（`#F4F6F8`）
   - **数値書式**: 整数は `#,##0`、`%` 列は `0%`
   - **条件付き書式**: 達成率（`%` 列）が 100% 以上で Gold、80% 未満で薄赤
   - **オートフィルタ**: ヘッダー行に自動付与
   - **フリーズペイン**: ヘッダー行 + 1 列目をフリーズ
   - **シートタブ色**: Navy
   - **印刷設定**: 横向き A4 / フィット幅 / タイトル行繰り返し / ヘッダー中央にタイトル / フッター左に "AKKODiS Internal Use" / 右にページ番号
   - **チャート**（`[chart]` 指定時）: 表の右側に棒グラフを配置、データラベル付き
   - **表記補正**: 全セル文字列に `notation.py` を適用

## ブランドルール（要点）

- カラー: Navy `#001F33`, Gold `#FFB81C`, White, Light Gray `#E0E4E8`
- フォント: Noto Sans JP / Inter（11pt 標準、ヘッダー Bold）
- 数値: 3 桁カンマ、通貨は「千円」「百万円」を列単位で統一
- 結合セルは多用しない（フィルター・ソート・関数が阻害されるため）

詳細は `brand/style-guide.md`。

`pip install openpyxl`

## トラブルシュート

- **チャートが表示されない**: `[chart]` 指定したシートの 1 列目が文字列・以降に数値列が必要。空の表ではチャートは作られない。
- **% 列の色分けが効かない**: ヘッダーに「率」または「%」を含む列を `0%` 形式で書く。条件付き書式は Excel 起動時に評価される。
- **フォントが反映されない**: ローカルに Noto Sans JP が無い環境では Yu Gothic / Meiryo にフォールバックされる（ブランド規約上 OK）。
