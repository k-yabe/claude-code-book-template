# AKKODiS ブランドガイド（XLSX 用 抜粋）

## カラー

| 用途 | HEX |
|------|------|
| ヘッダー背景 | `#001F33`（Navy） |
| ヘッダー文字 | `#FFFFFF` |
| 強調セル背景 | `#FFB81C`（Gold） |
| 警告セル背景 | `#F4C7C3`（薄赤、達成率 80% 未満） |
| ゼブラ偶数行 | `#F4F6F8` |
| 罫線 | `#E0E4E8` |
| 本文 | `#000000` |

## フォント

- 日本語: Noto Sans JP（フォールバック: Yu Gothic, Meiryo）
- 欧文・数字: Inter / Arial
- サイズ: 本文 11pt / ヘッダー 11pt Bold / タイトル 16pt Bold

## 数値書式

| 種別 | 書式 |
|------|------|
| 整数（人数・件数） | `#,##0` |
| 金額（円） | `¥#,##0` |
| 金額（千円・百万円） | `#,##0` + 列ヘッダーに単位明記 |
| パーセント | `0.0%` |
| 達成率 | `0%`（小数なし） |
| 日付 | `yyyy/mm/dd`（業務報告内では `2026年4月28日` 形式の文字列も可） |

## レイアウト

- 列幅: 自動調整、最小 12 / 最大 40
- 行高: 標準 18pt、ヘッダー 24pt
- フリーズペイン: ヘッダー1行 + 左1列をフリーズ
- 印刷向き: 横、A4、フィット 1ページ幅
- セル配置: 数値は右寄せ、文字列は左寄せ、ヘッダーは中央

## シートの命名規則

- 概要シートは `01_Summary` または `00_概要`
- データシートは `02_Data_<内容>`
- グラフシートは `03_Chart_<内容>`
- 目的別に命名し、シートタブ色は Navy

## 禁止事項

- 派手なグラデーション・3D エフェクトの使用
- 1 シートに表 4 つ以上を詰め込む
- 罫線を太線で全マス引く（読みづらさにつながる）
- 結合セルの多用（後続のフィルター・ソート・関数を阻害する）
