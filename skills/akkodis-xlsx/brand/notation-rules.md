# AKKODiS 表記ルール（Writing Checker 準拠）

このファイルは AKKODiS Japan の文章表記ルールをまとめたもので、`apps/writing-checker/knowledge.js`（社内 Writing Checker の知識データ）と同一内容を Skill 用に Markdown として再パッケージしたものである。

文書（PPTX / XLSX / DOCX）を生成するときは、本ルールを必ず適用すること。誤った表記は AKKODiS のブランド毀損につながるため厳格に守る。

## 適用順序

1. **D. IOWN® 表記ルール**（最優先・コンプライアンスリスク）
2. **B. AKKODiS ブランドガイドライン**（固有名詞・サービス名）
3. **C. Microsoft 製品・サービス表記**
4. **A. 記者ハンドブック準拠 表記ガイド**（一般日本語表記）

固有名詞や IOWN® 表記が一般ルールと衝突した場合、固有名詞・IOWN® ルールを優先する。

## A. 記者ハンドブック準拠 表記ガイド

### 【1】接続詞・つなぎ言葉・副詞
ビジネス文書では接続詞・副詞はひらがな表記が原則（法的文書・契約書では漢字も可）。
- および → ひらがな推奨（法的文書・固有名詞内は「及び」可）
- ならびに → ひらがな推奨
- または → ひらがな推奨（法的文書は「又は」可）
- もしくは → ひらがな統一（「若しくは」はNG）
- ただし → ひらがな統一（「但し」はNG）
- なお → ひらがな統一（「尚」「猶」はNG）
- したがって → ひらがな統一（「従って」はNG）
- つまり → ひらがな統一（「詰まり」はNG）
- さらに → ひらがな統一（「更に」はNG。「更なる」も同様）
- また → ひらがな統一（「又」はNG）
- かつ → ひらがな（「且つ」はNG）
- ついては → ひらがな統一（「就いては」はNG）
- しかし → ひらがな統一（「然し」はNG）
- しかも → ひらがな統一（「然も」はNG）
- すなわち → ひらがな統一（「即ち」はNG）
- ところが → ひらがな統一（「所が」はNG）

- むしろ → ひらがな統一（「寧ろ」はNG）
- あえて → ひらがな統一（「敢えて」はNG）

- もっとも → 接続詞・副詞の場合はひらがな（「尤も」はNG。最上級の「最も」は漢字）

### 【2】数字・数量
- 個数・数量・順序・年月日・時刻・番号は算用数字（半角）を使用
- 全角数字（１、２、３）は使用しない
- 単位と数字の間にスペースを入れない（例: 10km、500円、3GB）
- 大きな数字は「万」「億」を使う（例: 1億2,000万円）
- パーセントは%記号と半角数字（例: 85%）
- 序数は「第○」形式（例: 第1回、第3四半期）
- 慣用句・固有名詞・概数・熟語的表現は漢数字（例: 一般的に、三権分立、数十年）
- カ月（「ヵ月」「ヶ月」はNG）
- 人数を示す場合は「1人」（「独りでに」の「独り」は別用法）

### 【5】句読点・記号
- 読点「、」は意味の区切り・主語の後・接続詞の後に打つ
- 句点「。」は文末に必ず打つ（箇条書きの末尾は任意）
- 中黒「・」で並列する語句をつなぐ（読点で代用しない）
- 感嘆符「！」疑問符「？」はビジネス文書では原則使用しない

### 【6】敬語・ビジネス表現
- いただく（補助動詞）→ ひらがな（「頂く」はNG）
- ください（補助動詞）→ ひらがな（「下さい」はNG）
- おります（補助動詞）→ ひらがな（「居ります」はNG）
- お伺いする → 「お伺いいたします」は二重敬語でNG
- 拝見する → 「お拝見します」は二重敬語でNG
- 「ご覧いただく」が正しく「拝見いただく」は誤用
- 貴社（文書）／御社（口語）で使い分ける
- 「〜させていただく」多用はNG。「〜いたします」で十分なケースが多い

### 【7】形式名詞・補助動詞のひらがな書き
形式名詞（実質的な意味が薄れて文法的に使われる名詞）と補助動詞はひらがなで書く。
- こと → 形式名詞はひらがな（「〜する事」はNG → 「〜すること」。ただし「事件」「事故」「事業」など実質名詞は漢字）
- ところ → 形式名詞はひらがな（「〜したところ」の「所」はNG。ただし場所を表す場合は漢字「所」可）
- とおり → 形式名詞はひらがな（「〜のとおり」の「通り」はNG。ただし道路の「〜通り」は漢字可）
- ため → 目的・原因はひらがな（「〜のため」の「為」はNG。ただし「為替」など熟語は漢字）
- ほか → 形式名詞はひらがな（「その他」の「他」はNG → 「そのほか」）
- うえ → 形式名詞はひらがな（「〜したうえで」の「上」はNG。ただし位置の「上」は漢字）
- うち → 範囲を表す場合はひらがな（「〜のうち」の「内」はNG）
- できる → 可能を表す場合はひらがな（「出来る」はNG → 「できる」。ただし「出来事」「出来栄え」は漢字）
- ある → 補助動詞はひらがな（「〜して有る」「〜して在る」はNG → 「〜してある」。ただし存在の「有る」「在る」は漢字可）
- いる → 補助動詞はひらがな（「〜して居る」はNG → 「〜している」。ただし存在の「居る」は漢字可）
- いく → 補助動詞はひらがな（「〜して行く」はNG → 「〜していく」。ただし移動の「行く」は漢字）
- くる → 補助動詞はひらがな（「〜して来る」はNG → 「〜してくる」。ただし移動の「来る」は漢字）
- みる → 補助動詞はひらがな（「〜して見る」はNG → 「〜してみる」。ただし視覚の「見る」は漢字）
- おく → 補助動詞はひらがな（「〜して置く」はNG → 「〜しておく」。ただし設置の「置く」は漢字）
- もらう → 補助動詞はひらがな（「〜して貰う」はNG → 「〜してもらう」）
- あげる → 補助動詞はひらがな（「〜して上げる」はNG → 「〜してあげる」。ただし物理的に上げる場合は漢字）
- ほしい → 補助形容詞はひらがな（「〜してほしい」の「欲しい」はNG。ただし独立形容詞「物が欲しい」は漢字可）

### 【12】助詞・文構造の注意点
- 「の」の3連続は避ける（例: 「会社の部長の意見の要約」→ 「会社部長の意見要約」など言い換える）
- 「〜たり」は2回以上セットで使う（例: 「読んだり書いたりする」。「読んだりする」と1回だけはNG）
- 「〜が、〜が」と「が」を1文で2回使わない（主語のねじれ防止）
- 「〜は〜は」と「は」を1文で2回使わない（意味の曖昧さ防止）
- 「全然〜ない」が標準。肯定文「全然大丈夫」はくだけた表現であり、ビジネス文書ではNG
- 「〜することができる」は冗長。「〜できる」に短縮できないか検討する
- 一文が長すぎる場合は分割を検討する（目安: 80文字以上）

- 社外文書で自社の人間に敬称は付けない（「弊社の田中部長」ではなく「弊社の田中」「弊社部長の田中」）

### 【18】句読点・記号（追加）
- 全角と半角の混在はNG。英数字は半角、日本語は全角で統一する
- 括弧の種類：「 」は会話・引用、『 』は書名・作品名、（ ）は補足説明
- 半角カッコ ( ) はプログラムコード以外では使わない。日本語文中では全角（ ）を使う
- 三点リーダーは「……」（2つ連続）が正式。「・・・」「。。。」「...」はNG
- ダッシュは「――」（2つ連続）が正式。「——」「ーー」（長音2つ）はNG
- 中黒「・」はカタカナの並列に使う（例: 経済・社会・環境）。漢字の並列には読点「、」を使う
- 全角スペースは原則使用しない（字下げ以外）

### 【19】数字表記（追加）
- 4桁以上の数字にはカンマを入れる（例: 1,000　10,000　100,000）
- 小数点は半角ピリオド（例: 3.14）
- 電話番号はハイフンで区切る（例: 03-1234-5678）
- 年月日は「2026年4月9日」形式。「2026/4/9」「2026.4.9」はビジネス文書では避ける
- 時刻は「10時30分」「10:30」のいずれか。「10時半」は口語的でビジネス文書には不向き
- 西暦を使用する。和暦を使う場合は西暦を併記する（例: 令和8年（2026年））
- 範囲を示す場合は「〜」を使う（例: 10〜20人）。「～」（波ダッシュ）と「〜」（全角チルダ）の区別に注意
