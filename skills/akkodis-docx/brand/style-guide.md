# AKKODiS ブランドガイド（DOCX 用 抜粋）

## カラー

| 用途 | HEX |
|------|------|
| 見出し / 表紙背景 | `#001F33`（Navy） |
| アクセント / 下線 | `#FFB81C`（Gold） |
| 本文 | `#000000` |
| キャプション | `#5A6470` |
| 罫線 | `#E0E4E8` |

## フォント

- 日本語: Noto Sans JP / フォールバック Yu Gothic, Meiryo
- 欧文: Inter / Arial
- 表紙タイトル: 32pt Bold（Gold on Navy）
- 見出し1: 18pt Bold（Navy）
- 見出し2: 14pt Bold（Navy + Gold 下線）
- 見出し3: 12pt Bold（Navy）
- 本文: 11pt Regular（Black）
- 注釈: 9pt Regular（Light Gray）

## レイアウト

- 用紙: A4 縦
- 余白: 上下 25mm / 左右 22mm
- 行間: 1.5
- 段落前後: 8pt / 8pt
- 表紙はページ単独（次の見出しは改ページ後）

## ヘッダー / フッター

- ヘッダー: 左に文書タイトル、右にページ番号（Navy 1pt Gold 下線あり）
- フッター: 左に AKKODiS ロゴ（小、`AKKODIS_Logo_RGB_BLUE.svg` または PNG 変換版）、中央に「AKKODiS Internal Use」または「AKKODiS / Confidential」、右に作成日

## 表

- ヘッダー行: Navy 背景 + 白文字 Bold
- 罫線: Light Gray 細線
- セル余白: 4pt
- 数値: 3桁カンマ、右寄せ

## 注意事項

- 1行が長すぎる場合は読点で区切る（記者ハンドブック準拠）
- 箇条書きの末尾は句点を付けない（または全項目で統一する）
- 「ですます」「である」のスタイルを文書内で混在させない
- 二重敬語に注意（`brand/notation-rules.md` 第15章を参照）
